# Переход к текстурированию

После явного принятия конкретной геометрии используй парный weapon-asset-texturing. Он обслуживает PBR всех предметов, включая мебель и инструменты; название сохранено для совместимости.

Не повторяй здесь правила UCUPaint: единый авторинг, материалы, заводская отделка с интервью и каталогом, физический масштаб, проверки API и выдача находятся в парном скилле; износ и состояния (для нового оружия — одно рабочее 100%) — в weapon-asset-wear поверх принятой отделки. При обычной совместной установке его файл расположен в соседней папке ../weapon-asset-texturing/SKILL.md. Если парный скилл недоступен, найди его в установленных навыках; не заменяй нативные слои произвольными нодами.

Переход разрешён уже данным принятием: повторно не спрашивай. Для новой существенной правки формы верни только затронутую геометрию на просмотр. Если повреждённый вариант 20% заказан, он сохраняется отдельно от неповреждённой основы.
