# Каталог заводских отделок: карточки, выбор, перенос на модель

Одна и та же деталь в разных отделках «как в интернет-магазине», у каждой карточки — код и точные числа. Карточку и
деталь модели строит **одна** функция стека Painter `build_finish` (`tools/asset_kit/finish/sp_finish.py`), поэтому
выбранное на карточке ложится на модель теми же слоями и числами. Порядок слоёв и запреты — по AR-15 «ГРАНЬ-15»
(`tools/ar15/sp_ar15.py`, словари BASE и GRAIN) и [урокам](factory-finish-lessons.md).

## Где что лежит

| Что | Где |
|---|---|
| Данные каталога: группы, умолчания рода, отделки с кодами и числами | `tools/asset_kit/finish/finishes.json` |
| Стек Painter (карточка и модель) | `tools/asset_kit/finish/sp_finish.py` — `build_finish`, `build_set`, `card` |
| Мост к Painter (свой экземпляр, своя папка заданий) | `tools/asset_kit/finish/sp_run.py` (мост — `tools/vss_m_v8/sp_bridge`) |
| Образец (брусок 120 × 36 × 24 мм со стволом, пазом, карманом, осью, винтом, гайкой, рифлением) | `tools/asset_kit/finish/sample_build.py` → `_asset_src/finish_catalog/sample` |
| Сборка каталога | `tools/asset_kit/finish/catalog.py` (maps → cards → blend → page) |
| Кадры и файл Blender | `tools/asset_kit/finish/render_cards.py` |
| Страница и выбор | `tools/asset_kit/finish/catalog_server.py`, шаблон `catalog_page.html` |
| Каталог для владельца | `E:/Models Blender/Каталог отделок`: `index.html`, `catalog.json`, `Карточки/<код>_studio.jpg`, `<код>_outdoor.jpg`, `Карты/<код>/` (2K glTF: baseColor, ORM, normal), `Каталог_отделок.blend`, `Образцы владельца/`, `выбор.json` |
| Проект Painter образца | `_asset_src/finish_catalog/sp/finish_sample.spp` |

Всё — обычный Python (страница — стандартная библиотека) и Blender/Painter по путям проекта: одинаково запускают
Claude и Codex.

## Команды

```text
python -X utf8 tools/asset_kit/finish/sp_run.py start            # свой Painter с мостом
python -X utf8 tools/asset_kit/finish/catalog.py sample           # только при новом образце: сетка, проект, запекание
python -X utf8 tools/asset_kit/finish/catalog.py all [КОД,КОД]    # карты → кадры → Каталог_отделок.blend → страница
python -X utf8 tools/asset_kit/finish/catalog_server.py --spec "<папка модели>/finish-spec.json"   # страница выбора
python -X utf8 tools/asset_kit/finish/sp_run.py quit             # закрыть свой Painter, когда отделка кончилась
```

Страница — `http://localhost:8765/`; в Claude Code её открывают во встроенном браузере (preview по адресу), владелец
может открыть и в своём. Без `--spec` выбор идёт в избранное `выбор.json` каталога. Карточка 57 отделок: карты ~3 с,
два кадра Cycles 128 ~9 с на отделку. Painter держит видеопамять — свой экземпляр закрывай.

## Код и числа карточки

Код `ГРУППА-ЦВЕТ-БЛЕСК` (латиницей): `AN-BLK-MAT` — анодирование чёрное, мат; `CK-FDE-RGH` — порошок песок,
шершавый; `HT-TI` — побежалость титана. Ступени блеска: глянец ≤ 0,2, атлас 0,3–0,45, мат 0,55–0,65, шершавый ≥ 0,7 с
рельефом зерна. У каждой отделки — только естественные для неё ступени (решение владельца 2026-10-30).

| Поле | Что строит `build_finish` |
|---|---|
| `base` | заливка: цвет sRGB, шероховатость, металличность, высота 0,5 (уровень, вокруг которого работает Overlay) |
| `material` | вместо заливки — материал Painter (`carbon_fiber`, `wood_plain`) с параметрами, трёхпроекционно, плитка `mm` |
| `kind` | умолчания `kinds`: `coating` — кромки только глаже (светлые кромки цветом читаются вытертыми), `metal` — светлее и глаже, `glass` — без объёма |
| `edges`, `cavity`, `gradients` | кромки по кривизне, углубления по AO (Multiply и матовее), два крупных мягких градиента (clouds, масштаб 0,4) |
| `grain` | Overlay гауссова шума в блеск, цвет и рельеф; `mm` — ячейка в мм, масштаб = разрешение / (32 · мм · пикс/мм) |
| `layers` `ramp` | переход цвета вдоль оси детали: ступени по запечённому положению (`mg_position`) с порогом и мягкостью, `warp` — неровный край |
| `layers` `blotch` | пятна закалки: цвет по крупным шумам с порогом (`[цвет, шерох., металл, доля, период, шум]`) |
| `layers` `brushed` | шлифовка: анизотропный шум в блеск, цвет и рельеф, период `mm` вдоль наибольшей оси |
| `layers` `stipple` | точки литья по 3DG (светлые глаже, тёмные углублённые матовее, на рёбрах нет), размер `dots_mm` |
| `layers` `flow` | следы течения пластика — мягкие разводы в блеске |
| `render` | то, чего нет в картах: лак (`coat`), стекло (`transmission`, `ior`), тонкая плёнка (`thin_film`), бархат (`sheen`) — Principled в Blender |
| `godot` | как это будет в игре; clearcoat у оружия не брать (выходит стеклянно), тонкой плёнки в Godot нет |
| `use`, `origin` | где применяется; откуда числа (принятый ствол, ролик, правило) |

Образец — 2K, ~10,9 пикс/мм: плотность оружия в руках в игре (10–12), зерно на карточке такое же, как на модели при той
же плотности. Числа заданы в мм, поэтому переносятся на набор с другой плотностью.

## Выбор владельца → файл спецификации

`finish-spec.json` — рядом с моделью (в папке ассета библиотеки), его пишет страница и агент, читают Claude и Codex:

```json
{"schema": "ring-finish-spec/1", "asset": "…", "model": "<.blend>", "stage": "factory",
 "slots": [{"id": "receiver", "title": "Ресиверы и цевьё", "parts": ["Upper", "Lower"], "finish": "CK-FDE-MAT",
            "overrides": {}, "note": ""}],
 "interview": [{"q": "…", "a": "…"}], "favorites": [], "requests": [], "history": [], "accepted": false}
```

- Создать со слотами: `python -X utf8 tools/asset_kit/finish/catalog_server.py --new-spec "<файл>" --asset "<имя>"
  --model "<.blend>" --slot receiver:Ресиверы:Upper,Lower --slot barrel:Ствол …`
- Страница: «Выбрать» пишет `slots[].finish` и строку в `history`; ★ — избранное; «Образец / замечание» — картинки и
  текст в `Образцы владельца` и в `requests`. `accepted` ставит агент после «принимаю» владельца по файлу просмотра.
- `gradients.scale` в `overrides` — во сколько раз пятна крупных градиентов мельче карточки (у длинной узкой детали
  пятна карточки крупнее её самой; затвор АСТЕН-919 — 1,7). Список `layers` в `overrides` заменяет список карточки
  целиком.
- `overrides` — правки чисел поверх карточки для этой модели (например, `{"base": {"rough": 0.55}}`), с причиной в
  `note`. Повторяющаяся правка — повод для новой карточки, а не для тихой подстройки.

## Перенос на модель

1. Наборы текстур и сетки по слотам: в Painter — `st.material().all_mesh_names()`; плотность набора (пикс/мм) — из
   развёртки (как `density()` в `sample_build.py`), наибольший размер набора — для трёхпроекционных узоров.
2. Стек набора одной командой: `sp_finish.build_set(<набор>, [{"finish": "CK-FDE-MAT", "meshes": [...]}, …], px_mm,
   bbox_mm)` — группа «Этап 1 — заводская отделка», в ней подгруппа на отделку, резкость 0,3 эффектом группы.
   Отделку с `overrides` передавай записью (`dict`) — `sp_finish.finish(код)` с изменёнными числами.
3. Надписи и знаки (вымышленные) — поверх, маской из развёртки, как `tex_marks.py` AR-15.
4. Выгрузка — пресет glTF (`sp_lib.export`), файл просмотра со студией прямо в нём; `render` карточки → в Principled
   файла просмотра так же, как в `render_cards.material`.
5. В UCUPaint (если ствол ведётся в нём): те же числа — основа, кромки, AO, градиенты, зерно с масштабом в мм; особых
   слоёв в UCUPaint нет — собирай их маской и Ramp вручную и записывай соответствие в asset-state.md.

## Новая отделка

Добавь запись в `finishes.json` (код по схеме, группа, ступень, числа, `use`, `origin`), собери
`catalog.py all <КОД>` и посмотри обе карточки. Новый вид особого слоя — функция в `build_finish` (не отдельный стек
для одного ствола). Образцы владельца из `Образцы владельца` — основание для новой карточки: запиши файл в `origin`.

## Проверено на карточках (2026-10-30)

- Студия: софтбоксы 4 / 1,2 / 2,5 Вт на 0,45 м и студийная HDRI 0,35 — сильнее пересвечивает чёрное до серого.
- Карбон `carbon_fiber`: плитка 12 мм давала «сетку» мельче миллиметра — 50 мм ≈ жгут 2–3 мм; тёмные цвета 0,24 / 0,06
  при металле 1 — иначе плетения не видно под лаком.
- Дерево `wood_plain`: свой цвет светлее (орех 0,52 / 0,34 / 0,19) и `veins_color_variation` 0,8 — иначе бурая
  заливка без рисунка.
- Закалка: пятна с периодом меньше 2 см читаются камуфляжем — периоды 2,5–5.
- Пресет glTF выгружает и сетку (`Untitled.gltf/.glb/.bin`) — карточке не нужна, `catalog.py` её удаляет.
