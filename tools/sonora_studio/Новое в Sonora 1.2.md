# Sonora Studio 1.2 — звук и варианты для Ring

Запуск: ярлык **Sonora Studio** на рабочем столе. Установка находится в `D:\ПРОГРАММЫ\Sonora Studio`; точный исполняемый файл указан в свойствах ярлыка. Прежние файлы сохранены в «Резервных версиях». Если при обновлении прежняя Sonora была открыта, новая версия установлена в подпапку `Версии`, чтобы сохранить текущую работу.

При первом запуске обновления **сохраните проект в прежнем открытом окне, закройте его и запустите Sonora с ярлыка**. Уже открытая программа продолжает работать на старой версии.

## Компрессор

Выберите дорожку, откройте снизу **Компрессор**, включите галочку. Для речи начните с **Ровный голос**, для оружия — с **Сохранить удар**. Опустите порог до нужного снижения уровня на индикаторе. Более медленная атака пропускает больше первого удара; «Доля» смешивает обработку с исходным звуком. Есть все основные параметры, график и три пресета. Настройки работают во время воспроизведения и экспорта, сохраняются в `.sonora`, отменяются через Ctrl+Z. У старых проектов компрессор выключен.

## Высота и скорость

1. Выберите один или несколько фрагментов и нажмите слева **Мастерская звука**.
2. На вкладке **Высота и скорость** задайте высоту ±12 полутонов и скорость 50–200%. Независимый режим сохраняет длительность при смене высоты. Режим **Как скорость записи** связывает высоту со скоростью. Для голоса в независимом режиме есть сохранение формант.
3. Нажмите **Подготовить**. **Исходник A** и ▶ возле результата позволяют сравнить звук; есть петля и отдельная громкость прослушивания.
4. **Применить к фрагментам** сохраняет их начало и эффекты дорожки. Длительность может измениться, последующие фрагменты автоматически не сдвигаются. Оригиналы остаются в библиотеке; Ctrl+Z возвращает прежние фрагменты.

Можно обрабатывать и **Микс отмеченных дорожек** — весь проект либо выделение. Эффекты дорожек входят в микс один раз; мастер применяется после обработки.

## Набор шагов, механики или выстрелов

1. Откройте **Мастерская звука → Варианты и подготовка** и выберите пресет задачи.
2. Укажите количество и разброс высоты, скорости и уровня. Начните с небольших значений: для шагов ±0.4 полутона, для выстрелов ±0.25. Номер набора фиксирует случайные изменения; **Другой набор** даёт другие варианты.
3. Обрежьте тишину по краям, оставив запас для атаки и хвоста. Выберите RMS/пиковое выравнивание или сохраните исходный уровень. Потолок пика ограничивает общий уровень варианта; короткие переходы смягчают края. Пик и RMS в списке измеряются до эффектов дорожки.
4. Нажмите **Подготовить** и прослушайте варианты.
5. Выберите действие: **Добавить дорожки**, **Экспортировать** отдельные файлы WAV/MP3/OGG или **Передать в Ring** весь набор.

Новые варианты на дорожках находятся последовательно после конца проекта с запасом на хвост реверберации. Эффекты исходных дорожек копируются. Исходные фрагменты сохраняются на месте. При сохранении проекта обработанные звуки включаются внутрь `.sonora`.

На стенде Ring выберите событие и нужные варианты, режим добавления/замены, затем **Утвердить → Импортировать в Ring**. Передача на полку сама по себе не меняет игру. Импорт обновляет проект Godot; звук подхватывается при следующем запуске игры, для отдельной сборки требуется повторный экспорт.

## Практические пределы

- До 32 результатов и 10 минут суммарного аудио на один проход, каждый исходник до 2 минут. Предел редактора — 50 дорожек.
- Изменение высоты/скорости рассчитывается по кнопке «Подготовить». Компрессор, EQ, тембр и реверберация регулируются во время обычного воспроизведения.
- При отмене обработка останавливается после текущего файла. Подготовка сама не меняет проект; отдельные уже экспортированные файлы сохраняются при отмене экспорта.
- RMS не равен LUFS; автоматическое сравнение A/B с выровненной воспринимаемой громкостью пока не добавлено.

Регулятор атаки/хвоста, гейт, деэссер и сатурация остаются следующими расширениями. Советы под четыре типа звуков — в **«Инструменты для звуков Ring.md»** и справке Sonora.
