# Sonora Studio 1.6

Новое в 1.6: поиск и вкладки назначений, поверхности шагов и гильз по спискам владельца, окружение каждой готовой карты. В RING появился **«Звуковой стенд»** с категориями, моделями и звуками по алфавиту, прослушиванием и сохранением громкости события и отдельной записи. Подробности — **«Новое в Sonora 1.6.md»**.

Новое: **«Конструктор выстрела»** с пресетами небольшого помещения, большого помещения и улицы, вариантом с глушителем, разложением одной записи на пять слоёв и автоматической синхронизацией загруженной механики. Можно сразу создать шесть WAV или передать шесть вариаций на стенд Ring. Порядок работы — **«Новое в Sonora 1.5.md»**. Все возможности 1.4 сохранены.

**Ring, 21 октября 2026:** готовые записи воспроизводятся без постэффектов Godot. Тембр, динамику и акустику подготовьте в Sonora; для комнаты, большого зала и улицы можно назначить собственные варианты. В игре остаются 3D-положение, громкость по расстоянию/преградам и задержка распространения звука.

Локальная аудиомастерская для Windows x64. Монтаж, до 50 дорожек, параметрический эквалайзер и экспорт WAV, MP3, OGG. Для работы не нужны интернет, Python, Node.js или отдельно установленный FFmpeg.

## Запуск

Для обычной работы откройте папку `SonoraStudio` и запустите **`Sonora Studio.exe`**. Установка не требуется. При переносе на другой компьютер скопируйте **всю папку**: рядом с exe находятся необходимые ресурсы и кодеки.

На этом компьютере используется ярлык **Sonora Studio** на рабочем столе; программа расположена в `D:\ПРОГРАММЫ\Sonora Studio`. Если при обновлении была открыта прежняя версия, обновление устанавливается в подпапку `Версии`, а ярлык указывает на новую версию.

Отдельный файл `Sonora-Studio-1.5.0.exe` — дополнительная переносимая версия, которая сама распаковывает ресурсы при запуске. Первый запуск может занять около минуты; готовая папка приложения запускается без распаковки.

«Открыть пример» создаёт небольшой оригинальный звуковой этюд из трёх синтезированных слоёв. Нажмите Пробел и меняйте эквалайзер, чтобы услышать результат.

## Типы, слои и скорость

Выберите тип звука, откройте слой и нажмите **Загрузить варианты**. Один выбранный вариант каждого включённого слоя участвует в общем звучании. **Весь звук** показывает сборку целиком, **Новая комбинация** меняет незакреплённые варианты. Слева находится панель скорости выбранной дорожки; кнопка **1×** в её заголовке переводит к этому полю. Подробнее — **«Новое в Sonora 1.4.md»**.

## Добавление и монтаж

- **Добавить звуки / Ctrl+I** — импорт WAV, MP3 и OGG. Каждый файл попадает в библиотеку и на отдельную дорожку в позицию курсора. Несколько файлов на разных дорожках звучат одновременно.
- **+ у дорожки** — импорт в существующую дорожку. Несколько выбранных файлов размещаются последовательно.
- Перетащите файл с компьютера или исходник из библиотеки на дорожку. Двойной клик по исходнику в библиотеке добавляет его в позицию курсора на выбранной дорожке.
- **Дорожка / слой** — добавить свой слой с пустой дорожкой. До 50 слоёв в типе; обычно удобно работать с 5–10.
- Перемещайте фрагмент за середину; между дорожками он тоже перемещается. Перетаскивайте края, чтобы обрезать. Обрезка сохраняет исходник: край можно раздвинуть обратно.
- Поставьте курсор на линейке времени, выберите фрагмент и нажмите **S** или кнопку с ножницами. Разрез создаёт два независимых фрагмента без добавления затухания в точке разреза.
- **Shift + клик** выбирает несколько фрагментов. Их можно двигать вместе, копировать, дублировать и удалять.
- **Ctrl+J** склеивает выбранные фрагменты одной дорожки с сохранением их расположения, пауз, наложений, громкости фрагментов и плавных переходов. EQ и громкость дорожки продолжают действовать после склейки. Для соединения фрагментов вплотную передвиньте их границы друг к другу — привязка поможет.
- Позицию, начало в исходнике, длительность, усиление и плавные переходы выбранного фрагмента можно ввести числами в левой панели. Время — в секундах, переходы — в миллисекундах.
- Привязка работает к краям фрагментов, курсору и сетке 10 мс. Удерживайте **Alt**, чтобы временно отключить её.

## Прослушивание и петля

**Пробел** — воспроизведение / пауза сборки выбранного типа звука. Открытая вкладка слоя меняет только редактируемый слой; остальные включённые слои продолжают звучать. **Enter** — стоп и возврат в начало. **Home** — перемещение в начало.

Кнопка ▶ в заголовке дорожки слушает эту дорожку отдельно. **M** выключает дорожку, **S** в заголовке включает соло. Соло можно включить у нескольких дорожек. Это отдельная функция от клавиши S для разреза.

Петля включается кнопкой ↻ или клавишей **L**. Рядом выберите:

- **Весь звук** — от нуля до конца сборки текущего типа;
- **Дорожка** — от первого до последнего фрагмента выбранной дорожки, с её отдельным прослушиванием;
- **Выделение** — диапазон, выделенный перетаскиванием мыши на линейке или пустом месте таймлайна. Инструмент R позволяет выделять и поверх фрагментов. Минимальная длина петли — 5 мс.

Петли планируются по аудиочасам, без паузы между повторениями. Резкое различие значений на концах выделения может давать щелчок; для чистого стыка используйте границы с малой амплитудой или плавные переходы фрагмента.

## Эквалайзер

У каждой дорожки свой EQ. Исходно 10 полос; кнопкой **Полоса** можно добавить до 24. Нажмите крестик у полосы для удаления. Кнопка с номером временно отключает одну полосу. Кнопка питания отключает весь EQ для сравнения.

- **Частота**: 20–20 000 Гц.
- **Усиление**: −24…+24 дБ.
- **Q**: 0.1–18. Меньше Q — шире диапазон; больше Q — уже.
- **Bell** — параметрическая полоса. **НЧ полка / ВЧ полка** — нижняя / верхняя полка; Q для полок не используется. **Срез ВЧ / Срез НЧ** — фильтры низких / высоких частот; усиление для них не используется.

Перетаскивайте точки на графике для изменения частоты и усиления. Колёсико над графиком меняет Q выбранной полосы. Значения можно вводить числами. EQ, громкость и панорама изменяются во время воспроизведения; изменение чисел не останавливает звук.

Встроенные пресеты — отправные точки: «Плотный удар», «Приглушить верх», «Радио», «Добавить низ». Уровень мастера по умолчанию −6 дБ, чтобы оставить запас при сложении дорожек. Индикатор показывает перегрузку красным.

## Настройки из внешнего файла

Кнопка **Из файла** загружает JSON, CSV или TXT. Они содержат настройки полос EQ, а не аудиосэмплы. Диапазоны значений те же, что в интерфейсе. Число полос заменяется числом строк файла, максимум 24. Примеры лежат в папке `Примеры-EQ` готового комплекта (`examples` в исходном коде).

JSON:

```json
{
  "name": "Плотный, мягкий звук",
  "bands": [
    { "frequency": 80, "gain": 4, "q": 0.7 },
    { "frequency": 1000, "gain": 1.5, "q": 1 },
    { "frequency": 8500, "gain": -6, "q": 0.8 }
  ]
}
```

Необязательное поле `type`: `peaking` (по умолчанию), `lowshelf`, `highshelf`, `lowpass`, `highpass`. Необязательное `enabled: false` отключает полосу. Вместо объекта с `bands` можно использовать массив полос.

CSV:

```csv
frequency,gain,q
80,4,0.7
1000,1.5,1
8500,-6,0.8
```

Разделитель — запятая, точка с запятой или табуляция. Десятичная запятая поддерживается с разделителем `;`. Заголовки необязательны; без заголовков порядок — частота, усиление, Q, необязательный тип. Частота обязательна, отсутствующее усиление принимается за 0 дБ, отсутствующее Q — за 0.707. Кнопка сохранения у EQ сохраняет текущие полосы в JSON.

## Эффекты и компрессор

Нижняя панель: **Эквалайзер / Эффекты / Компрессор**. У дорожки свои EQ, быстрый тембр НЧ/СЧ/ВЧ, компрессор и реверберация; лимитер действует на общий выход. Порядок: EQ → тембр → компрессор → реверберация → громкость/панорама дорожки → мастер → лимитер. Обработка одинакова при прослушивании и экспорте; сохраняется в проекте. Старые проекты получают выключенный компрессор.

Компрессор: порог −60…0 дБ, сжатие 1:1…20:1, атака 0.1–100 мс, возврат 10–1500 мс, мягкое колено 0–24 дБ, усиление −12…+24 дБ и доля обработанного сигнала 0–100%. График показывает статическую характеристику; индикатор — фактическое снижение уровня. Пресеты: **Ровный голос / Плотный голос / Сохранить удар**. Подбирайте порог по записи; медленная атака оставляет больше начального удара. Каналы стерео связаны.

Крутилки меняются перетаскиванием вверх/вниз, колёсиком, стрелками или числом; Shift делает движение точнее. Двойной клик сбрасывает параметр. Изменение параметров не перезапускает воспроизведение.

## Мастерская звука

Кнопка **Мастерская звука** находится слева под добавлением файлов. Выберите фрагменты либо **Микс отмеченных дорожек**. Для микса можно взять весь проект или выделенный диапазон. Галочки дорожек определяют состав микса; M/S действуют на обычное прослушивание.

**Высота и скорость:** высота ±12 полутонов, скорость 50–200%. В независимом режиме высота сохраняет длительность, а скорость сохраняет высоту. Режим **Как скорость записи** связывает их. Сохранение формант полезно для голоса в независимом режиме. Нажмите **Подготовить**, сравните **Исходник A** с кнопкой ▶ у результата. Петля и громкость относятся к предпрослушиванию.

**Применить к фрагментам** заменяет их аудиоматериал, сохраняя начало на таймлайне и эффекты дорожек. Длительность может измениться; следующие фрагменты автоматически не сдвигаются. Исходные файлы остаются в библиотеке, **Ctrl+Z** возвращает прежнее состояние.

**Варианты и подготовка:** задайте количество (до 32 результатов за раз), разброс высоты, скорости и уровня. Номер набора делает результат повторяемым; **Другой набор** меняет варианты. Пресеты: шаги, механика, выстрелы, голос. Обрезка убирает только внешнюю тишину с заданным запасом до атаки и после хвоста. Выравнивание по RMS или пику работает перед разбросом уровня; затем применяется потолок пика и короткие переходы. Полностью тихий исходник требует снижения порога или отключения обрезки.

Измерители в списке показывают длительность, пик и RMS **до эффектов дорожки**. При предпрослушивании и экспорте применяются эффекты дорожки и мастер. Для микса эффекты дорожек уже включены в исходник; повторно они не накладываются. RMS — средний уровень, автоматического выравнивания воспринимаемой громкости по LUFS пока нет.

- **Добавить дорожки** — создаёт по новой дорожке на каждый исходный фрагмент с копией его эффектов. Варианты расположены последовательно после проекта с запасом на реверберацию. Оригиналы остаются на месте.
- **Экспортировать** — WAV 24 бита, MP3 или OGG, всегда 48 кГц. Несколько результатов сохраняются отдельными пронумерованными файлами в выбранной папке.
- **Передать в Ring** — весь готовый набор появляется во втором окне. Выберите событие, отметьте варианты, нажмите **Утвердить → Импортировать в Ring**. Простая передача на полку игру не меняет.

Ограничения мастерской: исходник до 2 минут, до 32 выходных звуков и до 10 минут общей длительности за одну подготовку. Обработка запускается по кнопке и может отменяться между файлами. Новые дорожки учитывают общий предел 50; в проекте не более 2000 исходников.

## Экспорт

Отметьте галочками нужные дорожки. Кнопка **Экспорт / Ctrl+E** предлагает:

- **Один микс** — отмеченные дорожки объединяются в один файл с сохранением наложений;
- **Отдельные файлы** — каждая отмеченная дорожка сохраняется в свой файл в выбранной папке. Можно сохранить общую длительность и паузы для синхронизации либо убрать внешние паузы каждой дорожки;
- **Один фрагмент** — только выбранный фрагмент, с его настройками и EQ дорожки.

При экспорте учитываются галочки, EQ, громкость и панорама. **M/S влияют только на прослушивание**. Пустые дорожки пропускаются. Можно экспортировать весь проект либо выделенный диапазон. Один проход экспорта ограничен 10 минутами; для обычных звуков до 10 секунд это ограничение несущественно.

Выход всегда стерео. Частота дискретизации: 44.1, 48 или 96 кГц. WAV: 16/24 бит PCM или 32 бит Float. MP3: 320 кбит/с. OGG: Vorbis, качество 8. Начальная настройка WAV — 48 кГц / 24 бита.

«Уменьшить уровень при перегрузке» ослабляет только сигнал с пиком выше −0.1 дБ. Это не компрессор и не усиление тихих файлов. Для сохранения значений выше 0 дБ в WAV Float отключите эту опцию. WAV и OGG подходят для точных границ; сжатие MP3 может давать небольшие задержки и отличия на границах при воспроизведении в других программах.

## Проекты

**Ctrl+S** сохраняет проект `.sonora`, **Ctrl+Shift+S** — его копию под другим именем. Проект содержит все дорожки, фрагменты, EQ, эффекты и копии исходных и добавленных обработанных аудиофайлов. Исходники на компьютере можно переместить после сохранения — проект продолжит открываться.

Сохранение — явное, по команде пользователя. При закрытии с несохранённой работой программа предлагает вернуться и сохранить её. Отмена/повтор хранит до 80 операций за текущую сессию. История отмены, текущее положение курсора и выделение не сохраняются между запусками.

## Исходный код и сборка

Нужны Node.js 24+ и npm. Для разработки:

```powershell
npm ci
node node_modules/electron/install.js
npm start
```

Для резервного декодирования, экспорта и высоты/скорости положите Windows x64 `ffmpeg.exe` в `vendor/ffmpeg.exe` (с поддержкой `libmp3lame`, `libvorbis` и `librubberband`). В архиве исходников он не дублируется; готовое приложение уже содержит его. Его также можно взять из `resources/bin/ffmpeg.exe` распакованного приложения или получить с официальных ресурсов FFmpeg.

```powershell
npm test
node tests/integration.cjs
node tests/production.cjs
node tests/fx-ring.cjs
node tests/ring-v2.cjs
node tests/ring-safety.cjs
npm run build
```

Интеграционные проверки запускают настоящее окно Electron, проверяют монтаж, фильтры, проекты и аудиоэкспорт. Для проверки упакованной сборки задайте `SONORA_TEST_EXECUTABLE` полным путём к `dist/win-unpacked/Sonora Studio.exe`. Протокол проверки и изображения интерфейса записываются в `../qa` относительно каталога исходного проекта. Готовая сборка пишется в `dist`.

Технологии: Electron 45, Web Audio (одинаковые фильтры для прослушивания и офлайн-рендера), FFmpeg, fflate. Внешние сетевые запросы в интерфейсе отключены. Лицензии и ссылки на исходники компонентов — в `THIRD-PARTY-NOTICES.md`.
