# Sonora 1.3 — понятные назначения звуков Ring

Запустите **Sonora Studio** с обновлённого ярлыка рабочего стола. Если прежнее окно открыто, сохраните проект и закройте его перед запуском обновления. Программа установлена в `D:\ПРОГРАММЫ\Sonora Studio\Версии\1.3.0`.

## Назначить звук оружию

1. Нажмите **Стенд Ring**. Слева выберите конкретную модель — например, **ПМ** (КОРС-9).
2. В середине выберите действие: выстрел, глушитель, помещение, магазин, затвор, осечка и т. д. У каждой модели собственные назначения. Одни и те же записи используются игроком, напарниками и врагами с этим оружием.
3. Справа **Добавить из папки** загружает WAV, MP3, OGG. Можно перетащить файлы или передать готовый набор из Sonora. Отметьте нужные варианты, сравните A/B.
4. Выберите замену или добавление вариантов, нажмите **Утвердить → Импортировать в Ring**. Файлы и назначение сохранятся автоматически, Godot импортирует ресурсы.

**Основной выстрел** — назначение этой пушки для обычных условий. **С глушителем** — отдельное назначение; обычный выстрел за него не подставляется. Записи для улицы, небольшого и большого помещения при наличии заменяют основной выстрел этой модели. Для глушителя предусмотрены свои три варианта места.

Если отдельная запись места не назначена, используется назначенный основной выстрел **той же пушки** без постэффектов. Такие строки помечены **«Основной»**. При отсутствии и основного назначения будет тишина. Другие пустые действия молчат.

По решению владельца от 21 октября 2026 постэффекты Godot убраны полностью. Нужные реверберацию, эхо, эквализацию и динамику подготовьте в записи или Sonora. Движок рассчитывает расстояние, направление, задержку распространения и уменьшает громкость за преградами; тембр и высоту записи он не меняет. Для комнаты, большого зала и улицы назначайте собственные готовые варианты. Общих оружейных наборов, семейств, отдельных записей «свой/чужой/вдали» и синтетических подстановок больше нет.

## Новый тип звука

Нажмите **+ Новый тип звука**, введите своё название и выберите **Когда звучит**:

- **Действие конкретного оружия** — выберите модель и свободное действие.
- **Игровое действие** — например, шаг по определённой поверхности, попадание или действие интерфейса.
- **Действие выбранной двери** — выберите действие, сцену и объект двери. Назначение касается выбранной двери.
- **При появлении объекта / запуске сцены** — выберите сцену и объект-источник; звук играет один раз либо в петле, пока объект находится в сцене.
- **Когда игрок входит в область** — выберите сцену, объект-центр и радиус. Область срабатывания создаётся автоматически.

После **Продолжить** добавьте файл справа, утвердите и импортируйте. Событие и привязка создаются вместе с назначением аудио; редактировать Godot вручную не требуется. Для существующего действия с назначенным звуком используйте его карточку для замены. Список действий отражает реализованную игровую механику; создание звука само по себе не создаёт новую механику.

Раздел **Другие события** показывает назначенные записи и созданные вами типы. Погода и прочие пустые заготовки не заполняют основной список. Автоматический ветер и синтез убраны. При желании фон можно создать через игровое действие **Фоновый звук мира**.

## Убрать или отменить

**Убрать звук** очищает выбранное назначение. **Удалить тип** удаляет созданное событие и его привязку; постоянные слоты оружия можно очищать. **Переименовать** меняет название.

Все изменения доступны в **Истории импорта**. Отмена сохраняет последующие ручные изменения и при конфликте сообщает о нём. Резервные копии от старой аудиосистемы сохранены в папках, а в новой истории показываются операции версии 1.3.

Изменения вступают в силу при следующем запуске игры. Для отдельно экспортированной сборки нужно повторно экспортировать Ring из Godot. Для замены звуков и создания перечисленных событий ручное редактирование проекта не нужно.

При переходе сохранены явные назначения ПМ и Glock, в том числе пять комнатных выстрелов ПМ. Неиспользуемые прежние записи вынесены из проекта в резервную папку внутри `D:\ПРОГРАММЫ\Sonora Studio\Резервные версии`. Из неё файлы можно снова выбрать при добавлении звука.
