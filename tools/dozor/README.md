# ДОЗОР — геометрический кандидат

Прототип выбран владельцем: Fenix TK16 V2.0. Имена: ДОЗОР Ф-1, Ф-1М, Ф-1С; крепёж ДОЗОР-П.
Текущий просмотр: `E:\Models Blender\WEAPONS\ДОЗОР — фонари и крепёж\models\DOZOR_Factory_Painter_v01.blend`.
Редактируемые слои: `painter/DOZOR_factory_v01.spp` в той же папке ассета.
Форма принята владельцем; v02 исправил маркировку. Заводская отделка сделана в Painter по
ответам владельца и ждёт просмотра. Износа нет. Источники формы v01/v02 сохранены.
Исходные игровые модели и FPS-руки не менялись.

`build_dozor.py` — исторический генератор геометрии v01. Он запускается установленным Blender 5.2.2 с `--background --factory-startup
--python-exit-code 1 --python <скрипт> -- --out <папка выдачи>`.
Не запускать генератор поверх последующих ручных правок. Три варианта разделены по коллекциям
и root, основные mesh data общие. Клипса съёмная, для кольца снимается. Свет направлен вдоль -X.

`integrate_markings.py` исправляет сохранённый принятый v01 в новый v02. Обычный Python с
`--asset <папка> --prepare-masks` создаёт 4 PNG-маски надписей; Blender с открытым принятым v01
и `-- --asset <папка>` встраивает их в нативные группы материала и удаляет FONT-объекты.
Слой меняет только цвет; форма, нормали, рельеф, геометрические тени и трансформы не меняются.
Материалы трёх вариантов привязаны к объектам, поэтому общие сетки сохраняются. Маски упакованы.
Скрипт проверяет SHA-256 принятого v01 и неизменность mesh/трансформов. Исторический v01 с
парящими буквами не является актуальной выдачей; не возвращать его маркировку в новые кандидаты.

`fetch_refs.py` скачивает фото производителя в игнорируемую папку `референсы/dozor`.
Это частные источники формы, не лицензированные текстуры. Реальных логотипов в ассете нет.
Длина 143 мм, головка 34 мм, трубка 25,4 мм. Мелкие детали оценены по фото.
Крепление по типу ALG-00; внутренний пружинный механизм не реконструирован.

`review_dozor.py` рендерит уже открытый сохранённый кандидат. После `--` указываются
`--out <папка>` и необязательно `--views 01,05,06`; `--save` сохраняет диагностическую студию.
Образец планки в коллекции REVIEW скрыт в модели и включается только в виде 10.

`audit_dozor.py` использует read-only аудит навыка с параметрами `--config` и `--output`.
Единственная адаптация: перед тесселяцией координаты грани сдвигаются к локальному нулю и
переводятся в миллиметры. Blender при расчёте в метрах отбрасывает некоторые корректные
микрограни. Площади затем считаются по исходным мировым координатам; критерии не ослаблены.
`inspect_dozor.py` сравнивает BMesh и тесселяцию для диагностики этого случая.

Проверки рядом с моделью в `checks`: габариты, замкнутость evaluated-сеток, проход кольца,
сквозные отверстия темляка и отсутствие пересечений с образцом планки проекта.
PASS относится к указанным критериям; визуальное сходство проверяется отдельно.

## Заводская отделка в Painter

`prepare_finish_spec.py` — группы реальных деталей для каталога; `finish-spec.json` хранит ответы
владельца и выбор. Чёрное анодирование AN-BLK-SAT, ободок SS-BRU, клипса NT-BLK-SAT,
крепёж AN-BLK-SAT / PH-BLK-MAT, кнопки RB-BLK-MAT, стекло GL-AR, отражатель CR-GLS.

`prepare_painter.py` создаёт отдельную копию с развёрткой: цельные цилиндрические острова
для точёных оболочек и Smart UV для остальных деталей, затем общая упаковка каждого набора.
В FBX попадает только PainterUV: старые UV примитивов занимают всю текстуру и перекрывают
остальные детали в Painter. Принятые исходники не меняются. FBX — вход авторинга, не игровая сетка.
Корпус — 4K (~111 пикс/см), крепёж 2K (~107 пикс/см), стекло 512. Заполнение high-poly атласа
корпуса 24% — ограничение текущей авторской развёртки; игровой атлас и оптимизация отдельным этапом.

`painter_control.py` работает только с отдельным мостом `_asset_src/dozor/painter_jobs`.
Свой Painter запускается с SUBSTANCE_PAINTER_PLUGINS_PATH=tools/vss_m_v8/sp_bridge и
SP_BRIDGE_DIR=<абсолютная папка заданий ДОЗОР>. Не использовать чужой открытый проект.
Порядок заданий: `painter_create.py` → дождаться `_project_ready.txt` → `sp_finish.bake()` →
дождаться новой `_bake_done.txt` → `painter_finish.py` → `_dozor_saved.txt` → `painter_export.py` →
`_dozor_exports_done.txt`. Существующие маркеры очищаются перед новым действием.

Отделки строятся штатным `sp_finish.build_set`, параметры те же, что на карточках. Геометрические
маски заданы и на группах, и на заливках. Надписи меняют только BaseColor. Три варианта букв
переключаются слоями; после экспорта в исходнике активен Ф-1. Технические LED-детали — керамика
и выключенный люминофор, отдельные заливки без emission. Маски надписей импортированы в .spp.

`assemble_painter_preview.py` кладёт реальные карты Painter на исходную high-poly с PainterUV,
упаковывает 15 texture nodes и HDRI, сохраняет просмотр в Rendered. `painter_inspect.py` и
`verify_factory.py` проверяют нативные слои, зависимости и неизменность геометрии. Самопроверка
`tools/asset_kit/review.py maps` запускалась с реальной UV-маской; фон вне островов исключён.
