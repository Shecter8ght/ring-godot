# ДОЗОР — геометрический кандидат

Прототип выбран владельцем: Fenix TK16 V2.0. Имена: ДОЗОР Ф-1, Ф-1М, Ф-1С; крепёж ДОЗОР-П.
Выдача: `E:\Models Blender\WEAPONS\ДОЗОР — фонари и крепёж\models\DOZOR_Family_form_v02.blend`.
Основная форма v01 принята владельцем. v02 исправляет способ нанесения маркировки: встроенная
маска цвета вместо отдельных букв. Полная заводская отделка и производственная UV ещё не выбраны.
Исходные игровые модели и FPS-руки не менялись.

`build_dozor.py` — исторический генератор геометрии v01. Он запускается установленным Blender 5.2.2 с `--background --factory-startup
--python-exit-code 1 --python <скрипт> -- --out <папка выдачи>`.
Не запускать генератор поверх последующих ручных правок. Три варианта разделены по коллекциям
и root, основные mesh data общие. Клипса съёмная, для кольца снимается. Свет направлен вдоль -X.

`integrate_markings.py` исправляет сохранённый принятый v01 в новый v02. Обычный Python с
`--asset <папка> --prepare-masks` создаёт 4 PNG-маски надписей; Blender с открытым принятым v01
и `-- --asset <папка>` встраивает их в нативные группы материала и удаляет FONT-объекты.
Слой меняет только цвет; форма, нормали, рельеф, геометрические тени и трансформы не меняются.
Материалы трёх вариантов привязаны к объектам, поэтому общие сетки сохраняются. Маски упакованы.
Скрипт проверяет SHA-256 принятого v01 и неизменность mesh/трансформов. Исторический v01 с
парящими буквами не является актуальной выдачей; не возвращать его маркировку в новые кандидаты.

`fetch_refs.py` скачивает фото производителя в игнорируемую папку `референсы/dozor`.
Это частные источники формы, не лицензированные текстуры. Реальных логотипов в ассете нет.
Длина 143 мм, головка 34 мм, трубка 25,4 мм. Мелкие детали оценены по фото.
Крепление по типу ALG-00; внутренний пружинный механизм не реконструирован.

`review_dozor.py` рендерит уже открытый сохранённый кандидат. После `--` указываются
`--out <папка>` и необязательно `--views 01,05,06`; `--save` сохраняет диагностическую студию.
Образец планки в коллекции REVIEW скрыт в модели и включается только в виде 10.

`audit_dozor.py` использует read-only аудит навыка с параметрами `--config` и `--output`.
Единственная адаптация: перед тесселяцией координаты грани сдвигаются к локальному нулю и
переводятся в миллиметры. Blender при расчёте в метрах отбрасывает некоторые корректные
микрограни. Площади затем считаются по исходным мировым координатам; критерии не ослаблены.
`inspect_dozor.py` сравнивает BMesh и тесселяцию для диагностики этого случая.

Проверки рядом с моделью в `checks`: габариты, замкнутость evaluated-сеток, проход кольца,
сквозные отверстия темляка и отсутствие пересечений с образцом планки проекта.
PASS относится к указанным критериям; визуальное сходство проверяется отдельно.
