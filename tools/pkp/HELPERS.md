# ПКП «Частокол»: как писать модуль детали (памятка исполнителю)

Строим подробную high-poly модель пулемёта по мотивам ПКП «Печенег» (6П41, классический) для игры RING. Только
форма, без текстур. Владелец принимает придирчиво: детализация предельная, острых кромок нет (у каждой кромки
скругление или фаска), примыкания деталей чистые, подвижные детали — отдельными объектами с осью.

## Способ
Детали — не булевы операции Blender, а **поля расстояний** на вокселях (numpy), сетку из поля делает OpenVDB.
Модуль `tools/pkp/sdf.py` — прочитай его целиком перед работой. Образцы готовых модулей: `part_receiver.py`
(штамповка из листа, заклёпки, накладки), `part_cover.py`, `part_barrel.py` (тела вращения, окна), `part_stock.py`.

- Единицы — миллиметры. Оси: **+X к дулу, +Z вверх, −Y — правая сторона стрелка**. X = 0 — передний торец
  ствольной коробки, Z = 0 — ось канала ствола.
- `F = Field(имя, lo, hi, h)` — габариты поля с запасом ≥ 1 мм вокруг тела. `F.add(тело, r, bbox=…)` — объединение
  с галтелью r; `F.sub(тело, r, bbox=…)` — вырез со скруглением кромки r; `F.apply(тело, "inter", r)` — пересечение;
  `F.displace(fn, bbox, fine=False)` — рельеф смещением поверхности; `F.shell(t)` — превратить тело в лист
  толщиной t (рельеф повторяется с изнанки — так делается штамповка).
- Тела: `box`, `box_e` (свои радиусы по осям), `cyl`, `cone`, `sphere`, `capsule`, `torus`, `plane`, `half`,
  `prism(Poly(fillet_poly(точки, радиусы)), "XZ", w0, w1, rim=…)` — контур × выдавливание со скруглёнными
  кромками, `prism2(плоская фигура…)`, `rect2 / circle2 / seg2 / union2 / minus2`, `revolve(Poly, "X", центр)`,
  `strip(Path2(fillet_path(…)), "XZ", толщина, w0, w1, rim)` — гнутая полоса, `wire(точки, r)` — проволока,
  `rot / move / both / union / inter / minus`. Надписи — `text2` + `engrave`.
- Готовые сетки (вместо поля): `lathe_mesh(профиль, seg, axis, c, closed, mats)` — тело вращения (патроны, трубки,
  оси), `helix_mesh` — витая пружина, `tube_mesh`, `join_meshes`. Функция детали тогда возвращает кортеж сетки.
- Функции тел получают массивы `X (nx,1,1)`, `Y (1,ny,1)`, `Z (1,1,nz)` — только операции numpy с вещанием.

## Грабли
- **Всегда давай `bbox`** местным операциям (`dims.bb(x0, x1, y0, y1, z0, z1)`): без него операция считается по
  всему полю. Деталь должна считаться секунды.
- Объединение с галтелью двух тел с общей плоской гранью вспучивает грань на 0,29·r; пересечение с совпадающей
  плоскостью усаживает. Стыки делай на плоскости (плоские фигуры `union2` → `prism2`), обрезаемое строй длиннее
  плоскости обреза, после галтели подрезай плоскость обратно (`F.apply(half(…), "inter", 0)`).
- Лист и тонкие стенки — не тоньше 4 вокселей при черновом расчёте (шаг черновика = 2·h из `parts()`).
  Шаг h: мелкие детали 0,06–0,1; средние 0,12–0,15; крупные 0,2–0,25.
- Скругление `rim` у `prism` меньше половины толщины выдавливания и меньше радиуса углов контура.
- Соседние детали не должны пересекаться: зазор 0,1–0,3 мм; посадки (ось в отверстии) — отверстие на 0,05–0,1 больше.
- Длинный heredoc с кириллицей в Bash падает — файлы пиши инструментом Write, скрипты запускай из файла.
- Python пишет CRLF — при записи файлов кодом указывай `newline="\n"`, кодировка UTF-8.

## Каталог деталей модуля
```python
def parts():
    return [
        dict(name="Bipod_Leg_L", build=leg_l, h=0.12, coll="Сошки", mat="Steel_blued", parent="Bipod_Yoke",
             pivot=[x, y, z],            # точка шарнира в мм — начало координат объекта (ось вращения — в отчёт)
             adapt=0.1),                 # необязательно: укрупнение граней в плоских местах
    ]
```
`mat` — из `assemble.MATS` (Steel_blued, Steel_phosphate, Steel_bare, Spring_steel, Polymer, Box_paint, Canvas,
Belt_steel, Case_lacquer, Bullet_jacket, Primer); у сетки с несколькими материалами — `mats=[…]`.
Копии одной сетки — `instances=[dict(name=…, matrix=[16 чисел по строкам, сдвиг в мм], parent=…, coll=…)]`.
Вариант, выключенный по умолчанию, — `coll_hidden=True` (вся его коллекция). Имена объектов — английские,
`Часть_Подчасть`; имена коллекций — русские.

  константами в начале своего модуля, у каждой комментарий, откуда она (какой снимок) или «оценка».
- Папка ассета: `E:\Models Blender\WEAPONS\Печенег — модель`. Образцы владельца — `refs\owner\01…16`
  (01–06 — цветные крупные планы, 07 — другой вариант с обвесом, не для формы; 08–16 — серые рендеры: 13 — правый
  бок, 14 — левый бок, 12 — спереди, 08/09/11/15/16 — ракурсы). Фото настоящего пулемёта — `refs\web\*`
  (опись `refs\web\sources.md`), размеры — `refs\web\dimensions.md`. Картинки смотри инструментом Read.
- Миллиметры с боковых рендеров: `python -X utf8 tools/pkp/ref_tiles.py "<снимок 13.png|14.png>" <папка> <имя>
  x0 y0 x1 y1 --zoom 5 --step 10 --mm --y <глубина>` — кусок снимка с сеткой в мм модели; `--y` — на сколько
  плоскость детали ближе к камере, чем средняя плоскость оружия (борт коробки — 22.5; деталь на оси — 0).
  Снимок 14 снят на 4° сверху: высоты надёжнее брать со снимка 13. Без `--mm` — сетка в пикселях (любой снимок).
  Куски складывай в `trace\<своя папка>`.
- Чего нет на образцах — ищи в интернете (WebSearch / WebFetch через ToolSearch), источник — в комментарий.
  Не выдумывай: неизвестное помечай «оценка» и перечисли в отчёте.
- Маркировка только вымышленная: название «ЧАСТОКОЛ», реальных клейм заводов и индексов на модели быть не должно.

## Запуск и проверка
```
PKP_TAG=<твоя метка> bash tools/pkp/go.sh 2 "<модули>" "<виды>"
```
`<модули>` — короткие имена модулей через пробел (`bipod`, `box ammo`); чтобы видеть деталь на пулемёте, один раз
посчитай с соседями (`"receiver cover barrel stock <свой>"`), дальше пересчитывай только свой модуль — остальное
в твоей папке сохраняется. Результат: `work\pkp_k2_<метка>.blend`, кадры `work\shots_k2_<метка>`, наложение на
образцы `work\cmp_k2_<метка>` (красное — кромки модели, зелёное — образца, жёлтое — совпало).
Виды: `ref13`, `ref14` (камерами образцов), `right`, `left`, `top`, `bottom`, `front`, `rear`, `q_front_r`,
`q_rear_r`, `q_rear_l`, `q_front_l`; свой вид — `имя:x:y:z:куда_x:куда_y:куда_z:ширина_мм` (ортография) или
с `:pNN` в конце (перспектива, объектив NN мм). Увеличить наложение:
`python -X utf8 tools/pkp/compare.py <shots> <refs\owner> <вывод> 13 --crop x0 y0 x1 y1 --zoom 3 --name _имя`.
Каждый кадр смотри сам (Read): форма, кромки, примыкания, пересечения с соседями. Правь, пока наложение
не сойдётся в 1–2 пикселя, а крупные планы не станут чистыми.

## Правила
- Правь **только свои файлы модулей**. `sdf.py`, `dims.py`, `build.py`, `assemble.py`, чужие `part_*.py` не трогай:
  нужна новая функция — определи её в своём модуле и скажи об этом в отчёте.
- Комментарии по-русски, о смысле (зачем), а не о синтаксисе; имена по-английски.
- Ничего не коммить в git. Не пиши на диск C: (он полон). Не трогай чужие процессы Blender и Python.
- В конце — отчёт (до 50 строк): какие детали сделаны; для каждой подвижной — точка шарнира, ось или направление,
  ход или угол (для рига); какие размеры оценочные; где наложение не сошлось и на сколько; что не сделано.
