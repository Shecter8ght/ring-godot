# ВЕРАС-54 — матовая отделка игровых материалов

Правка от 2026-10-09 по замечанию владельца о чрезмерном глянце.
Основа — GLB из `tools/export_veras54.py`, первоначальный перенос Claude Code
(коммит `28a51f9`). Геометрия и файлы Blender остаются прежними.

Импорт Godot 4.7.2 корректно выбирает UV и каналы ORM (G — Roughness,
B — Metallic). Причина блеска — параметры исходного чёрного покрытия:
типичные Roughness 0.49 и Metallic 0.48.

`tools/veras54_game_materials.py` корректирует упакованные карты только оружия:

- WeaponMetal: у покрытия Roughness обычно 0.69, Metallic около 0.04;
  открытая сталь (Metallic >= 0.8) сохраняет исходные значения.
- Furniture: полимер и резина — Roughness 0.70–0.88, Metallic 0.
- Magazine: полимер матовее; металлические участки сохраняют исходные значения.
- Markings: Roughness 0.70. Цвет, нормали и патроны не меняются.

Микровариация исходных карт сохраняется. Коррекция применяется автоматически
после нового экспорта; отдельно: `python tools/veras54_game_materials.py`.
Нужен системный Python с Pillow и numpy. Повторный запуск не усиливает эффект.

Скрипт дописывает новые изображения в GLB, сохраняя исходный бинарный блок.
Проверено равенство сеток, accessors, узлов, скелетов, анимаций, материалов и
карт рук, BaseColor и Normal. Повторный запуск оставляет SHA-256 GLB прежним.
Blender, риг и анимации рук при этой правке не открывались и не пересобирались.

Визуальная проверка: одинаковый дневной свет, вид от бедра, механический
прицел и мировая модель; снимки `docs/screens/veras_material_before_*` и
`veras_material_after_*`. Игровой прогон клипов завершён без ошибок,
`compile_check` — 0 ошибок. Нативные материалы Blender остаются исходными;
эта отделка относится к игровому экспорту.
