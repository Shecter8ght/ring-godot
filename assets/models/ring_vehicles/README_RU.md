# Транспорт RING для Godot

Девять собранных glTF-моделей: sedan, truck, bus × worn, damaged, wreck. У каждой модели четыре двери в отдельных glTF-файлах с pivot на петле. Все карты лежат в `res://assets/textures/ring_vehicles/`; пути в glTF уже настроены.

Список моделей, дверей и координат петель — в `manifest.json`. Редактируемые `.blend` и исходные фототекстуры — в `_asset_src/ring_vehicles/` (эта папка не коммитится). В проекте ещё нужно настроить коллизии, LOD и, при необходимости, анимацию дверей.
