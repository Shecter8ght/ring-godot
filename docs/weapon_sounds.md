# Звук Ring — назначения через Sonora 1.3

Каталог назначений: `data/audio_events.json` (schemaVersion 2). Его читает `Audio`.
Постоянные действия моделей — `data/weapon_sound_slots.json`, доступные игровые действия — `data/audio_actions.json`.
Пустой слот молчит; общих семейств, синтетики и записей дистанции нет. Дистанцию, преграды и акустику считает движок.

В Sonora: Стенд Ring → модель → действие → добавить запись → Утвердить → Импортировать.
«Новый тип звука» создаёт событие и привязку к действию, конкретной двери, появлению объекта или входу локального игрока в область.
Для дверей источником является сам Door; оружие и двери сохраняют существующую сетевую доставку эффектов.

Обычный выстрел и глушитель независимы. Если запись места не назначена, играет основной выстрел этой же модели с акустикой движка.
При отсутствии основного назначения — тишина. Назначенная запись помещения играет без дополнительного ревербератора.

КОРС-9 отображается как ПМ по имени в weapons.json. Сохранены пять его комнатных выстрелов и прочие явные записи ПМ/Glock.
Ненужные прежние записи вынесены в резервную папку Sonora на D, полный прежний код и данные находятся в архиве миграции.
Импорт/очистка/переименование/удаление типа отменяются через историю с проверкой последующих правок.
История старой схемы сохранена в папках резервных копий, её операции после миграции автоматически не откатываются.

Изменения читаются при следующем запуске игры. Для отдельного релиза требуется экспорт из Godot.
Новый звуковой тип привязывается к существующей механике; новую игровую механику имя и WAV не создают.

Проверки: `tools/godot.cmd --headless res://tools/sonora_weapon_contract_test.tscn`, `tools/godot.cmd --headless res://tools/compile_check.tscn`.
Старые `weapon_sounds_test` и `shot_layers_test` направлены на актуальную проверку договора назначений.

Если результат импорта не совпадает со стендом, проверьте версию запускаемой Sonora: для этого реестра нужна 1.3 или новее. Старые 1.1/1.2 записывают прежний sound_active.json и не обновляют текущие назначения. Восстановленные 2026-10-21 последние записи ПМ находятся в assets/audio/sonora; исходные файлы и история прежних импортов сохранены. Перезапуск игры обязателен, поскольку назначения загружаются при её старте.
