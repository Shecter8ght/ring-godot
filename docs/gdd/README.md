## Как продолжать

- Перед вопросом прочитать относящиеся к нему документы/код. Уже известное не спрашивать заново.
- Сначала закончить сверку вопросов A. Остаток давать короткими пачками, с вариантами и причиной рекомендации.
- Новый ответ сразу записать в анкету и журнал; обновить нужный раздел видения/GDD и STATE.
- «По умолчанию» относится только к предъявленной пачке. Отсутствие ответа ничего не утверждает.
- Импорт сохраняет источник, дату и границы одобрения. Статус «описано» не превращается в «решено».
- Если два прямых решения нельзя согласовать по их датам и области действия — показать одно конкретное противоречие владельцу.
- Числа для проверки и проектные расчёты отмечать отдельно от измерений. Поле `remaining` не скрывать.
- Подробную страницу механики писать перед работой над ней. Эта папка не дублирует таблицы Balance.

Новые вопросы получают новые ID; старые не перенумеровывать. В JSON `bank_question` сохраняет
оригинальную формулировку PDF, `question` — формулировку для RING/конкретной пачки.
`source_ids` ведут к каталогу источников в том же файле; `decision_refs` — к журналу.

## Что считается утверждённым

VIS-002, VIS-009, VIS-027, VIS-033, VIS-036, VIS-077 и VIS-079 утверждены прямыми ответами владельца 22 октября.
Старые подтверждённые решения продолжают действовать в пределах своих источников.
Остальной текст видения/GDD — редакционная сводка, а предложения/неполнота помечены явно.
Утверждать её целиком нужно после основных ответов A; повторно согласовывать уже одобренное не требуется.
