# Скиллы ассетов RING — Codex и Claude Code

Один поддерживаемый набор находится в `tools/asset_skills/`. Инструкции и справки одинаковы для обеих сред; только `agents/openai.yaml` предназначен для интерфейса Codex. Источники старых двух скиллов расширены, два новых созданы. Технические имена старых папок сохранены для совместимости существующих сценариев.

| Имя | Назначение |
|---|---|
| `blender-asset-workflow` | Предметная геометрия: пистолеты, дробовики, автоматы/винтовки, обвесы, патроны, магазины, ножи, гранаты, инструменты и неподвижные объекты |
| `weapon-asset-texturing` | Общий реалистичный PBR/UCUPaint для предметов и растений; обязательные 100/60/20 для огнестрельного оружия |
| `blender-vegetation-workflow` | Геометрия деревьев, кустов, травы и другой органической растительности |
| `godot-asset-preparation` | Заказанная игровая подготовка: сетки, bake, LOD, collision, экспорт и проверенный импорт |

## Решения владельца

- Нейросеть вправе самостоятельно искать в интернете референсы, фотографии, размеры, документацию и необходимые подходящие ресурсы. Обычный поиск не требует повторного разрешения; лицензии и ограничения инструментов сохраняются.
- При непонятной развилке или недостающих данных нейросеть не выдумывает решение: просит конкретный ответ, скриншот, изображение, фото, размеры или нужный ракурс. Зависимая часть ждёт ответа; независимая продолжается. Отсутствие ответа не означает принятие.
- Огнестрельное оружие: 100% идеальное, 60% лёгкие потёртости/сколы, 20% тяжёлые царапины, раковины, коррозия и утрата покрытия. Это художественные состояния, не площадь испорченных пикселей и не готовый игровой баланс.
- Геометрические дефекты 20% делаются отдельной копией и показываются вместе с основной формой до текстурирования. Каждая принятая геометрия сохраняется; исходник 100% не портится.
- Детали остальных семейств читаются из соответствующих справок. Новые проценты/сезоны/варианты для всех предметов автоматически не создаются.
- Сначала подтверждённая форма, затем PBR; игровой импорт — отдельный явно заказанный этап. Реализм проверяется по референсам и свету до дорогого полного запекания/рендеров.

## Установка на этом компьютере

`tools/install_asset_skills.py` проверяет входные файлы, относительные ссылки, Python-помощники и YAML. При доступном `skill-creator/scripts/quick_validate.py` использует официальный валидатор. PyYAML для текущей проверки находится только в `_asset_src/asset_skill_build/validation_deps`, системный Python не меняется.

Запуск с установленным Python:

```text
python -X utf8 tools/install_asset_skills.py --check
python -X utf8 tools/install_asset_skills.py --package
python -X utf8 tools/install_asset_skills.py --install --verify-installed
```

Установщик на текущем компьютере обновляет зарегистрированные `C:/Users/Schecter_8ght/.codex/skills` и `C:/Users/Schecter_8ght/.claude/skills`. Для новой установки Codex используется стандартный пользовательский `.agents/skills`, если прежний зарегистрированный каталог не найден. Можно явно указать `--codex-root` и `--claude-root`. Существующие четыре целевых папки копируются в `_asset_src/asset_skill_backups/<дата>/` до обновления. Остальные скиллы и настройки не изменяются.

Пакет `_asset_src/asset_skill_build/RING_Asset_Skills_Codex_Claude_Code.zip` содержит две готовые папки: `Codex` и `Claude_Code`; скопируйте содержимое выбранной папки в каталог навыков соответствующей среды. `manifest.json` хранит хеши; инструкция и CRC проверяются установщиком. Не устанавливайте второй набор с теми же именами одновременно в другой обнаруживаемый каталог.

Установка выполнена 2026-10-13: четыре скилла в каждой среде, восемь установленных копий. Прежние версии двух скиллов обеих сред сохранены в `_asset_src/asset_skill_backups/20261013-103529/`. Проверены официальный формат, 39 относительных ссылок, синтаксис трёх Python-помощников, совпадение общих файлов Codex/Claude Code и 90 файлов скиллов внутри ZIP. Отчёты находятся в `_asset_src/asset_skill_build/`.

## Вызов

Codex: `$blender-asset-workflow`, `$weapon-asset-texturing`, `$blender-vegetation-workflow`, `$godot-asset-preparation`.

Claude Code: `/blender-asset-workflow`, `/weapon-asset-texturing`, `/blender-vegetation-workflow`, `/godot-asset-preparation`.

Автоматическое применение разрешено по описанию задачи. Для обновлённого набора удобно открыть новую сессию. Проверка файлов/формата не является подтверждением, что конкретная будущая модель уже была изготовлена и проверена.

Одинаковые `references/working-rules.md` в самодостаточных пакетах берутся из одного `_shared/working-rules.md`. При изменении общих правил обновите эти четыре копии; проверка выявляет расхождение. Специфические правила семейства/материала держите в соответствующей справке. Дублировать все скиллы под каждое оружие/скамейку не нужно.

## Примеры маршрута работы

- Новый пистолет с обвесами: предметная геометрия → просмотр и принятие → PBR в 100/60/20. Заказанные повреждения сетки 20% показываются до текстурирования. Импорт в игру выполняется по отдельному поручению.
- Скамейка или лопата: предметная геометрия → принятие → материалы металла/дерева/пластика по референсам. Три состояния и оружейные обвесы автоматически не добавляются.
- Дерево: растительность → принятие формы → общий PBR с разделом коры/листвы. Сезонные варианты, ветер и игровые cards/LOD задаются отдельно.
- Не виден нужный стык или неизвестен материал: сначала поиск по имеющимся данным и источникам; если вопрос остался — конкретный запрос ракурса/решения владельцу. Спорный участок ждёт ответа.

Это примеры применения написанных правил; реальные задания на новые ассеты в рамках установки не запускались.

Документация формата: [OpenAI — Build skills](https://learn.chatgpt.com/docs/build-skills), [Claude Code — Skills](https://code.claude.com/docs/en/skills). Проверенные прежние аудит-помощники сохранены; новый набор не объявляет себя тестированием всех видов будущих ассетов.
