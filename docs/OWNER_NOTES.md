# RING — решения и предпочтения владельца (для любого агента)

Сводка того, что владелец решил и как он хочет работать. Раньше это жило только в локальной памяти
одного профиля Claude Code; перенесено сюда 2026-10-09, чтобы другой профиль или Codex начинал не с
нуля. Читать вместе с `AGENTS.md`, концом `docs/STATUS.md` и `docs/BACKLOG.md`.

## Как работать
- Владелец принимает решения и командует; руками работает агент. Перед работой `git pull --rebase
  --autostash`, после задачи — коммит СВОИХ файлов поимённо, push, запись в `docs/STATUS.md`.
- Незакоммиченные правки владельца в `scenes/` (его эксперименты в редакторе) — не коммитить, не
  откатывать, не включать в свои коммиты. `tools/build_release.cmd` собирает рабочую копию — такие
  правки попадают в RING.zip, предупреждать.
- Push: Git Credential Manager иногда виснет на невидимом окне входа; рабочий обход
  `git -c credential.helper= -c "credential.helper=!gh auth git-credential" push` (gh авторизован
  как Shecter8ght). LFS берёт тот же хелпер.
- Godot: 4.7.2 из Steam (`D:\Steam\steamapps\common\Godot Engine\godot.windows.opt.tools.64.exe`),
  запуск через `tools/godot.cmd`. Оконный запуск висел ~40 с на опросе геймпадов — в .cmd стоит
  `SDL_JOYSTICK_DIRECTINPUT=0`. Новые `class_name` — после `--headless --import`, иначе тесты не видят
  класс. Часть тестов (ai_test, range_test) без окна виснет на сохранении кадра — запускать с окном.
- Blender 5.2.2: `D:\ПРОГРАММЫ\Blender 5\blender.exe` (`--background --factory-startup`).
- Ответы владельцу — по-русски, просто, без жаргона.

## Графика и ассеты
- Цель — уровень Road to Vostok / Arena Breakout / Tarkov (мечта — Bodycam). Реализм: PBR,
  фототекстуры CC0, реальные пропорции; стилизацию не смешивать.
- **Без примитивов:** скриптовые модели из коробок и цилиндров отвергнуты. Сначала готовые CC0
  (Poly Haven — качать можно) или CC-BY (Sketchfab — качает ТОЛЬКО владелец, в чужой аккаунт и
  токены не входить); своё моделирование — только по фото-референсам, с превью до внедрения.
  Библиотека Sketchfab по статусам: `_asset_src/Zone01/Sketchfab/{0_новые,1_в_игре,
  2_можно_не_использовано,3_нельзя}`, разбор `tools/sketchfab_library.py`. Лицензии — в
  `assets/CREDITS.md`.
- `_asset_src/` (≈18 ГБ исходников) НЕ в git — владельцу советовали держать резервную копию.
- Блики: у самого источника ничего (лучи, ядро, ореол отвергнуты) — только едва заметные
  восьмиугольники-«зайчики» (LensFlare).
- Свет на улице зоны 1 владельцу нравится (мягкие тени, дымка, приглушённые цвета) — не ломать.

## Оружие и руки
- **FPS-руки делает владелец сам** в Blender (`E:\Models Blender\новые руки`): риг, хваты, анимации.
  Агент — только инструкции и ответы, без файлов, экспорта и Godot по рукам.
- Glock 17: красит владелец в UCUpaint (Substance нет); агент — геометрия, UV, запекание, экспорт.
  Файл покраски не перезапекать (`bake_maps.py` / `ucupaint_setup.py` затирают покраску).
  Новые детали пистолета — в НОВЫЙ текстурный набор. Порядок — `00_НАЧНИ_ЗДЕСЬ.txt` в папке модели.
- ИИ-генераторы 3D (Scenario) для оружия не годятся (сплошная сетка без деталей и рига) — оружие и
  прицелы делать в Blender по фото (как ПМ, Glock, ВСС); генерацию — для неподвижных предметов.

## Мир и карта
- Убежище — старая котельная в зоне 5, отдельный уровень; игра только от первого лица.
- Зона 1 «Район ТЦ»: детально только двор хрущёвок (объект 5), остальное блокаут. Ель и берёза —
  свои модели по фото владельца (`tools/build_spruce.py`, `build_birch.py`); клёны и тополя — ждут
  его фото.
- **Новую карту строит агент, но маленькими кусками и только по запросу владельца** — без его слова
  ничего не добавлять, идеи предлагать одной строкой (`docs/design/contracts_and_map.md`).
- Контракты: заказчиков пятеро, «тёмные» заказы отношения не портят.

## Баланс и механики (решения октября 2026)
- Ходьба −30 %, спринт вдвое дольше, остановка резче; любое оружие в любой слот; рюкзаки 20/30/45/60
  ячеек; враги видят до 100 м, стреляют по очереди (не больше двоих прицельно), замечают постепенно;
  бесконечные патроны у мародёров; смерть — регдолл; раненые лежат и отстреливаются.
- Смена суток: 1 игровой час = 5 мин, старт по выбору в убежище; точное время — в настройках.
