# Граната v09 — разные производственные фактуры High Poly

Кандидат **пока не принят**. По прямому заданию владельца выполнена только
задача 1; продолжение требует просмотра сравнений и явного подтверждения.

Файл для Blender:
`E:/Models Blender/From Scenario/Grenade/Codex_Texture_v09_Task1_На_проверку/Grenade_MkII_Studio_v09_Task1.blend`.
Он содержит полную редактируемую High Poly и четыре нативных стека UCUPaint.
Принятая v08 сохранена; точные резервные копии двух файлов v08 лежат в
`_asset_src/grenade_codex/materials_v09_stage1/backup_v08`, SHA-256 совпадают.

Заменён общий рисунок литья в трёх производственных слоях головки, скобы и
проволоки. У головки отдельное компактное зерно; у скобы слабая структура
листового металла; у кольца, ушка и проволоки — тонкие следы волочения.
Направление идёт по существующей полосе/кривой через отдельные метрические UV,
а не по глобальной оси объекта. Фактура корпуса оставлена целиком.
Новые карты процедурные, не сканы.

Шесть PNG16: два 4096² для головки, два 4096² для скобы и два 4096×2048
для проволоки. Физические размеры, амплитуды в метрах и RMS зафиксированы
в `textures/manufacturing/manifest.json`. Пространственная структура Roughness
различается; исходное распределение значений и интенсивность слоя сохранены.
Base Color, Metallic, базовый Roughness, Specular/IOR/Anisotropy не правились.

Все 56 слоёв, 66 прежних масок, полосы и солнце + «СЛНШК» сохранены.
Повторное открытие подтвердило неизменность семи сеток, прежних UV и
атрибутов, родителей, shape keys, драйверов и света. Все 28 изображений
встроены и совпадают с относительными внешними файлами по SHA-256.
Сравнения — три пары PNG16 1920², Cycles 256, одинаковые камера/свет/
экспозиция/seed, без denoise/DOF. В чат переданы полноразмерные сравнения
и фрагменты; галерея, ролик и презентация не создавались.

Рецепт: `tools/grenade_manufacturing_maps_v09.py`; Blender
`tools/grenade_surface_v09.py -- inspect`, затем отдельно `-- patch --family
head|lever|wire`, `-- finish`, `-- verify`, `-- compare --samples 256`;
`tools/package_grenade_surface_v09.py compare`, `deliver`.
Запускать из проекта; полная сборка старой v08 не нужна и не выполнялась.
Материалы заменяются в копии существующего файла, геометрия не пересоздаётся.
