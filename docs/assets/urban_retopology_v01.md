## Повторение

Скрипты: `tools/urban_screens/retopo`. Запуск Blender: `--background --factory-startup
--python-exit-code 1 --python <скрипт> -- <параметры>`.

1. `inventory.py` — исходные бюджеты, без записи мастеров.
2. `build.py --resume` — сетки, геометрические проверки и изображения сетки.
3. `bake.py --resume` — материалы; разделение партии: `--shard 0/4` … `3/4`.
   Повторная развёртка выбранных предметов: `--ids R04,U19_01 --fresh-uv`.
4. `lettering.py` — точные сплошные цвета надписей в ранее запечённых кандидатах.
5. `previews.py --resume` — три вида сохранённого кандидата с его SHA-256.
6. `compare.py` — численные сравнения с native-изображениями.
7. `delivery.py --resume` — переносимая выдача и финальные проверки после открытия.

После намеренного изменения генератора нужный этап запускается для выбранных ID заново:
`--resume` проверяет сохранённые файлы, но не отслеживает все изменения рецепта автоматически.
