## Как построено

`tools/npc_kit/armor_kit.py` — детали по поверхностям в метрах: выпуклые сечения торса поверх одежды
(рукава не в счёт), жёсткие пакеты плит одного радиуса с наклоном по груди/спине (могут поджать куртку на
1,2 см), мягкие пакеты с окантовкой и набивкой, стропа MOLLE с закрепками через 38 мм, лямки по плечу
(мимо трикотажного воротника), камербанд по контуру торса с обходом пакета, воротник по эллиптическому
цилиндру шеи, наплечники вокруг руки, фурнитура (фастексы, лестничные пряжки, кольца, трос).
`armor_mid.py` — плитоносец по параметрам (CarrierSpec), его же основа у крутой (`armor_top.py`);
`armor_poor.py` — бомжовская. Развёртка у каждой детали — метры, под фото-ткань.

Пересборка: `blender --background --factory-startup --python-exit-code 1 --python tools/npc_kit/armor_{poor,mid,top}.py
[-- render] [deliver=<папка>]` (читает `_asset_src/npc_kit/npc_scav_<версия>.blend`).
