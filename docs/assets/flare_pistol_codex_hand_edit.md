# Ракетница Codex — правка рук и ключей в Blender

Открывай **`E:\Models Blender\Ракетница — Codex\game_codex\source\flare_pistol_codex_fps_animations.blend`**.
Это редактируемая сцена с исходными FPS-руками ВЕРАС-54, их весами и IK. Позы кистей — заготовка
для твоей ручной доводки; особенно проверь большой палец при взведении, обхват рукояти и пальцы
левой руки на стволе. Ракетница держится правой рукой. Левая появляется при открытии и заряжании.

Файл подготовлен в Pose Mode с выбранными контролами кистей и клипом `Flare_Codex_reload_empty`.
Скорость — **30 кадров/с**, полный цикл — **1–156** (5,167 с). Маркеры таймлайна подписаны.

## Кости

Арматура — **`FPS_ArmsRig`**. Сетки — `FPS_Arms_Right` и `FPS_Arms_Left`.

| Что править | Кости / объекты |
|---|---|
| Положение и поворот правой кисти | **`ik_hand.R`** |
| Положение и поворот левой кисти | **`ik_hand.L`** |
| Локти и плечи | `upper_arm.R/L`, `forearm.R/L`; работают через исходные IK constraints |
| Кисти | `hand.R/L`; их поворот берётся из соответствующего `ik_hand` |
| Указательные пальцы | `f_index.01.R/L`, `.02.R/L`, `.03.R/L` |
| Большие пальцы | `thumb.01.R/L`, `.02.R/L`, `.03.R/L` |
| Остальные пальцы | кости `f_middle`, `f_ring`, `f_pinky` с суффиксами `.01–03.R/L` |
| Весь пистолет | **`Frame`** |
| Переламываемая часть | **`Barrel`** |
| Курок, спуск, защёлка, боёк | `Hammer`, `Trigger`, `Latch`, `FiringPin` |
| Новый патрон / старая гильза | `NewRound` / `OldRound` |

Если переносишь весь пистолет, двигай `Frame` и `ik_hand.R` вместе, чтобы хват не расходился.
Для движения кисти сначала правь `ik_hand`, затем пальцы. Сохрани существующие constraints и
веса сеток. Все кости рук имеют ключи; после изменения поставь ключ **Location/Rotation/Scale**
на нужном кадре. Для управления локтем проверь исходные IK constraints на предплечье.
Если хочешь вращать плечо/предплечье напрямую, временно уменьши Influence соответствующего
IK constraint: при Influence = 1 решатель перекрывает ручные повороты этих костей. Для кисти
аналогично учитывай Copy Rotation на `hand.R/L`. Экспорт запечёт конечный результат constraints.

## Кадры перезарядки

| Кадры | Действие |
|---|---|
| 1 | Исходная поза, только правая рука |
| 9–16 | Левая подходит и отпускает защёлку |
| 16–30 | Левая открывает ствол до 48° |
| 30–36 | Левая отпускает ствол и уходит |
| **33–42** | Правая переворачивает раскрытую ракетницу казённым срезом вниз |
| **45–48–50** | Первое встряхивание: вниз, затем возврат |
| **53–56–60** | Второе встряхивание; к 58 гильза вышла, к 65 падает из кадра |
| **60–70** | Правая возвращает ракетницу в положение для заряжания |
| 70–91 | Левая приносит новый патрон и совмещает его со стволом |
| **91–110** | Левая вставляет патрон |
| 110–117 | Левая отпускает патрон и отходит |
| **117–123–128** | Правая делает рывок вниз, ствол закрывается и фиксируется |
| **131–144** | Правый большой палец взводит курок |
| 144–156 | Возврат в готовность, остаётся правая рука |

Ключи между этими этапами оставлены редкими и с линейной интерполяцией, чтобы их было удобно
править. Экспорт семплирует каждый кадр и сохраняет результат IK в GLB. В начале `reload_empty`
показывается пример с использованной красной гильзой; если ракетница совсем пустая, игра скрывает её.

В Custom Properties арматуры: `preview_new_green` = 1 показывает зелёный новый патрон, 0 — красный;
`preview_old_green` переключает старую гильзу; `preview_has_old` = 0 скрывает старую гильзу.
`preview_reload_frame` и `left_hand_active` ведутся ключами: показ патронов и левой руки следует клипу.
Игра отдельно переключает цвет по выбранному боеприпасу.

самостоятельны и переданы для редактирования; в игре используется полный цикл.

## После ручной правки

Сохрани редактируемую сцену. В PowerShell из `E:\Games\RING-godot`:

```powershell
& 'D:\ПРОГРАММЫ\Blender 5\blender.exe' --background --factory-startup --python-exit-code 1 --python tools/animate_flare_pistol_codex.py -- export 'E:\Models Blender\Ракетница — Codex\game_codex\source\flare_pistol_codex_fps_animations.blend'
python tools/audit_flare_pistol_codex.py
python tools/register_flare_pistol_codex.py
tools/godot.cmd --headless --import
tools/godot.cmd --headless res://tools/flare_pistol_test.tscn
tools/godot.cmd --windowed --resolution 1600x900 res://tools/flare_pistol_shots.tscn
```

Команда **`export`** читает указанный тобой файл и пишет GLB/запечённую копию в проект;
она сохраняет исходную сцену с IK. Команда **`author`** генерирует ключи заново — после ручных
правок её не запускай. При изменении длительности или моментов вставки/закрытия также обнови
кадры в `tools/register_flare_pistol_codex.py`. Полный цикл игры: B — выбрать следующий тип,
R — перезарядить, ЛКМ — выстрелить.
