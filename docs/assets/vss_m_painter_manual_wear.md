# ВСС-М v8: износ руками в Substance Painter

Для владельца (2026-10-27). Вы сами рисуете износ, блеск, грязь и следы рук там, где нужно, вашими масками из
`E:/Models Blender/Маски_АЛЬФА`. Процедурная основа стека остаётся: генератор кромок, места износа, грязь в углах.
Вы её дополняете или стираете кистью.

## Коротко

1. Откройте Painter ярлыком: `tools/vss_m_v8/painter_open.cmd receiver` (коробка) или `… parts` (все остальные
   детали). Двойной щелчок по `painter_open.cmd` без аргумента откроет пустой Painter.
2. В списке наборов текстур (Texture Set List) выберите набор. Раскройте нужный слой и щёлкните верхний слой в его
   маске — **«РУКАМИ»**.
3. Возьмите кисть, в свойствах кисти поставьте альфу из полки (Assets → Your assets → Alphas → `RING_Маски_АЛЬФА`).
   **Белым** добавляете то, что делает слой (износ до металла, блеск, грязь), **чёрным** убираете.
4. Ctrl+S, затем File → Export Textures (настройки — ниже).
5. Закройте Painter и запустите `bash tools/vss_m_v8/painter_to_game.sh receiver` (имена наборов, которые меняли).
   Или напишите Claude «перенеси ручной износ в игру».

## Что подготовлено

- **Ярлык `tools/vss_m_v8/painter_open.cmd`.** Запускает Painter с тем цветовым управлением (OCIO), с которым
  созданы проекты. Без него Painter спрашивает про цвет и может перевести проект в старую схему. Ещё ярлык подключает
  мост `sp_bridge`, через который Claude по вашей просьбе может выгрузить карты или проверить слои; работать он вам
  не мешает. Стартовые окна «Home screen» и «What's new» мост закрывает сам.
- **Слои «РУКАМИ».** Это пустой слой рисования, который лежит сверху маски каждого слоя износа, грязи и следов, во всех
  наборах обоих проектов. Пока вы в нём ничего не нарисовали, маска такая же, как была.
- **Ваши маски в полке Painter.** Все 199 масок скопированы в
  `C:\Users\Schecter_8ght\Documents\Adobe\Adobe Substance 3D Painter\assets\alphas\RING_Маски_АЛЬФА` с теми же
  папками, что в `Маски_АЛЬФА`. В полке (Assets) их проще всего найти поиском по имени: «Кромка», «Отпечаток»,
  «Сколы». Если папка мешает, её можно просто удалить — проекты от неё не зависят.
- **Копии проектов до ручной правки:** `_asset_src/vss_m_v8/sp_receiver/receiver_до_ручной_2026-10-27.spp` и
  `_asset_src/vss_m_v8/sp_parts/parts_до_ручной_2026-10-27.spp`.
- **Защита от скриптов Claude.** Наборы с «РУКАМИ» помечены в самом проекте (метаданные `ring` / `manual_sets`).
  Пересборка стека скриптом на них останавливается с ошибкой, так что нарисованное не сотрётся. Пересобрать набор
  заново Claude может только по вашему прямому слову, и тогда ручная работа в этом наборе пропадёт.

## Как рисовать

1. **Выберите слой рисования.** Выделите набор в Texture Set List, раскройте слой в стеке (стрелка слева). Справа у
   слоя — чёрно-белая миниатюра маски; под ней стек маски, сверху в нём «РУКАМИ». Щёлкните «РУКАМИ»: кисть будет
   рисовать в маске этого слоя, а не в цвете.
2. **Кисть.** Инструмент Paint (кисть) на левой панели. В свойствах кисти:
   - **Alpha** — перетащите из полки вашу маску (например, `Кромка_04_Прямая_широкий_контакт`). Без альфы кисть
     круглая и мягкая.
   - **Цвет (Grayscale)** — 1 = белый (добавить), 0 = чёрный (убрать). При рисовании в маске клавиша X меняет белый
     и чёрный местами; если не сработает — ползунок.
   - **Size, Flow, Hardness** — размер, сила за проход, жёсткость края. Размер удобно менять, ведя мышью влево-вправо
     с зажатыми Ctrl и правой кнопкой.
   - **Spacing** — шаг отпечатков при протягивании. Чтобы альфа ставилась штампом (одна дуга, один скол),
     поставьте 100–200 % или просто щёлкайте по одному разу.
   - **Angle** — поворот альфы. Кромку из маски поворачивайте вдоль ребра.
3. **Прямая вдоль кромки:** щёлкните в начале, затем Shift + щелчок в конце.
4. **Смотрите на грань прямо.** Кисть ложится по поверхности под курсором, на скошенной грани отпечаток растягивается.
5. **Проверка.** Alt + щелчок по миниатюре маски показывает в окне саму маску. C перебирает каналы в окне (цвет,
   шероховатость, металл…), M возвращает материал. Отмена — Ctrl+Z.
6. **Только ваше, без процедурного.** В стеке маски выключите «глазом» генератор (Metal Edge Wear) или заливку ниже
   «РУКАМИ» — останется только нарисованное. Включить обратно можно в любой момент.

Советы по месту, исходя из того, как устроен предмет:
- до металла — у кромок, о которые трутся детали и рука: паз рукоятки взведения, губа горловины магазина, дуга под
  рычагом предохранителя, скосы «ласточкина хвоста», выступающие углы;
- вокруг вытертого — шире и мягче «05 Покрытие истончилось», иначе пятно выглядит наклейкой;
- на прикладе места хвата темнее и лоснятся («10 Засалено руками»), сколы — редкие, у кромок окон и затыльника.

## Сохранить и выгрузить карты

Ctrl+S, затем **File → Export Textures**:

| Настройка | Значение |
|---|---|
| Output directory | receiver.spp → `E:/Games/RING-godot/_asset_src/vss_m_v8/sp_receiver/export`; parts.spp → `E:/Games/RING-godot/_asset_src/vss_m_v8/sp_parts/export` |
| Output template (пресет) | **glTF PBR Metal Roughness** |
| File type | png, 8 bit |
| Size | как у набора (по умолчанию) |
| Padding | Dilation infinite («бесконечно») |
| Наборы | отметьте те, что меняли |

Файлы должны выйти с прежними именами: `<набор>_baseColor.png`, `<набор>_occlusionRoughnessMetallic.png`,
`<набор>_normal.png` — они заменят старые.

## В игру

Закройте Painter: он держит видеопамять, и без этого запекание уходит на процессор и идёт в разы дольше. Затем:

```bash
bash tools/vss_m_v8/painter_to_game.sh receiver wood --scenes
```

- В аргументах — наборы, которые меняли; без них перепекутся все атласы.
- `--scenes` — пересобрать сцены для осмотра в папке сдачи (студия, стол, сочетания).
- `--shots` — снимки в игре в `docs/screens/vss_iron_*.png`.
- Запекание занимает 5–15 минут, подробный журнал — `_asset_src/vss_m_v8_game/painter_to_game.log`.

Наборы попадают в атласы игры так: receiver, steel_parts, suppressor, bare_steel → Steel; sleeve → Cerakote;
handguard, rubber → Polymer; wood → Wood; магазины и патрон → Mags.

Можно и не запускать самому, а написать Claude «перенеси ручной износ в игру»: он выгрузит, перепечёт, проверит в игре
и закоммитит.

## Чего не трогать

- Слои «01 Покрытие», «01 Основа: …», «01 Дерево» — основа материала. Ступенька высоты у «06 Вытерто до металла» —
  тоже: она даёт кромке свет.
- Не перемещайте «РУКАМИ» ниже других эффектов маски: внизу его закроет генератор.
- Проекты большие (parts.spp — около 1,5 ГБ), сохранение занимает время.
