## Материалы (узлами, для просмотра)

- Кожа куртки — Poly Haven `brown_leather` (CC0, плитка 0,32 м по развёртке лекал), темнее в заломах,
  потёртости на гребнях складок; нитка в тон.
- Трикотаж — свой рубчик 4 мм. Брюки — свой камуфляж «чешуя» (4 тона + ячейки с тёмной каймой),
  плетение саржи по Poly Haven `denim_fabric_03`, пыль книзу.
- Берцы — `brown_leather` мельче, рант — соты, подошва — резина, металл фурнитуры, сетка языка.
- Балаклава — Poly Haven `jersey_melange` (вязка, обесцвечено, ворс).
- Кожа рук — ядро MakeHuman (CC0) с подповерхностным рассеянием; глаза — `brownlight_eye`.
- Швы и строчка — свои карты рельефа и масок по развёрткам (`_asset_src/npc_kit/tex_gen`).

В `assets/` пока ничего не внесено; при игровом экспорте фото-источники — в `assets/CREDITS.md`.

## Пересборка (Blender 5.2, `--background --factory-startup --python-exit-code 1 --python`)

`tools/npc_kit/body.py` → `boots.py` → `pants.py` → `jacket.py` → `balaclava.py` → `assemble.py`
→ `details.py` → `deliver.py -- <папка>`. Аргумент `render` — снимки в `_asset_src/npc_kit/…`.
Симуляции: брюки ~1 мин, куртка ~2,5 мин (RTX 5070 Ti, процессор).
