# Зона 1 · Район ТЦ — уровень с рельефом (блокаут + детальный двор хрущёвок)

Сцена: `scenes/levels/zone01_mall.tscn` (маршрут «Зона 1 · Район ТЦ» в убежище, доступен сразу).
План — `docs/design/contracts_and_map.md` §6 и концепт-карта владельца; масштаб подогнан под ТЦ Ø175:
игровая область ~840 × 510 м (контур — неровный многоугольник), 0.39 км². Север = −Z, центр ТЦ — (0, 0).

## Что сделано

| Часть | Состояние |
|---|---|
| Рельеф | насыпь +6.2 м с разрывом путепровода, овраг −10 м с ручьём, холм +16 м, восточный склон под гаражами +6, выемка погрузки −4 и тоннель, подиум ТЦ +1.5, насыпь отстойников +3; дороги врезаны по сглаженному профилю |
| Поверхность | шейдер `district_terrain`: 6 фототекстур Poly Haven (газон, редкая трава, листва, грязь, камень, щебень) по маске + камень на крутых склонах |
| Зоны 1–4, 6–14 | серый блокаут (масса ТЦ с куполом и порталом, паркинг 3 уровня с мостом на 2F, погрузка, площадь, рынок, АЗС, гаражи уступами, недострой 9 эт. с краном, холм с мачтой и дотом, подстанция и отстойники, мост и дома у оврага, насыпь с путями, блокпост) |
| Зона 5 — двор | **детально**: 3 хрущёвки (2 панельные 1-464, кирпичная 1-447) — свои модели по фото-референсам; проезд кольцом, тротуары с бордюрами, лавки, фонари, площадка (качели, горка, карусель, дуга, песочница), контейнерная площадка с баками, сушилки, газонные дуги, гаражи и «ракушки», сараи, деревья, сухая трава |
| Окружение | ~1800 деревьев (лесополоса, склоны оврага, вокруг холма, тополя у насыпи, лес за границей), 90 тыс. пучков сухой травы |
| Небо | днём — HDRI Nqweba Dawn (CC0) через `HdriSky`, низ панорамы (склоны, горы) заменён дымкой; погода смешивает (Balance.HDRI_WEATHER) |
| Игровое | 4 точки входа, 5 эвакуаций, 14 точек ИИ, 12 «комнат» для спавна, навигация из кэша (`data/navigation/zone01`) |

Брошенные машины во дворе и все постройки вне двора — пока блокаут-коробки.

## Пересборка

```
python tools/build_zone01.py               # рельеф, маска, массивы текстур, мир, блокаут, растительность, данные сектора
python tools/build_zone01_materials.py     # материалы слотов моделей двора
"D:/ПРОГРАММЫ/Blender 5/blender.exe" --background --factory-startup --python tools/build_khrushchevka.py
"D:/ПРОГРАММЫ/Blender 5/blender.exe" --background --factory-startup --python tools/build_zone01_props.py
python tools/build_zone01_foliage_textures.py   # кора берёзы, листва, трава (свои текстуры)
python tools/build_zone01_yard.py          # сцена двора (перезаписывает zone01_yard05.tscn)
tools/godot.cmd --headless --import
tools/godot.cmd --headless res://tools/bake_zone01_nav.tscn   # после любых правок геометрии
tools/godot.cmd res://tools/zone01_shots.tscn                  # снимки docs/screens/zone01_* + FPS по точкам
```
Снимкам можно задать условия: `ZONE01_TIME=day|dusk|night`, `ZONE01_WEATHER=clear|rain|fog|heat`,
`ZONE01_ONLY=yard,plaza`, замер без частей: `ZONE01_PERF=nograss,notrees,noterrain,noshadow`.

Генераторы перезаписывают свои сцены — ручные правки раскладки вносить в них, не в .tscn.
Новые узлы: `DistrictTerrain` (рельеф), `DistrictPaving` (покрытие по ломаной на рельефе),
`DistrictModel` (GLB + материалы слотов + коллизии из манифеста), `DistrictScatter` (MultiMesh по
клеткам из JSON), шейдеры `district_terrain`, `facade_aged` (старение фасадов), `district_water`, `hdri_sky`.

## Производительность (RTX 5070 Ti, 1920×1080, без VSync, день)

Двор ~90–175 к/с, овраг ~70–180, площадь ~50–90 (первый кадр прогона — компиляция шейдеров).
Главные потребители — трава (альфа-отсечение) и шейдер рельефа; деревья ~6 тыс. треугольников.
Дальше: дальние LOD деревьев (карточки), склейка повторяющихся пропов двора в MultiMesh.

## Модели со Sketchfab: куда класть и как понять статус

Библиотека — `_asset_src/Zone01/Sketchfab/` (не в git):

| Папка | Что значит |
|---|---|
| `0_новые/<категория>/<модель>/` | сюда класть скачанное (архивы как есть + ссылка) |
| `1_в_игре/` | встроено в игру (какой `.glb` — в списке) |
| `2_можно_не_использовано/` | лицензия подходит, пока не встроено — причина в списке |
| `3_нельзя/` | лицензия не подходит (Free Standard, NC, ND, SA) — в игру не пойдёт |

Разбор: `python tools/sketchfab_library.py` (лицензия из архива + API Sketchfab, распаковка, перенос по
статусу, список `_СПИСОК.md` в библиотеке и [docs/assets_sketchfab.md](assets_sketchfab.md)).
Встраивание: `tools/import_sketchfab.py` (таблица MODELS) → снова `sketchfab_library.py`.
