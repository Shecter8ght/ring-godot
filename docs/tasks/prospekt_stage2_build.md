**Числа брать из словарей `tools/prospekt_stage2_plan.py`** (координаты сцены, метры; X — восток, Z — юг), модуль

расстановка вещей в зонах) — брать из функций листов и описания, недостающее решать по смыслу и перечислять в сдаче.

## Как вносить правки

Патчами, как в первой очереди: `python -X utf8 tools/prospekt_patch.py <этап>` →
`data/blockouts/prospekt_patch_<этап>.json` → `tools/godot.cmd --headless res://tools/prospekt_apply_patch.tscn -- <этап>`.
Этапы этой очереди называть `s2_1a_…`, `s2_1b_…` и так далее; повторный запуск этапа не должен плодить дубликаты.
Перед этапом — `git pull --rebase` (если мешают чужие незакоммиченные правки — `git fetch` и проверить, что
`origin/main` не ушёл вперёд по файлам этапа) и копия `scenes/levels/prospekt_study.tscn`, `prospekt.tscn`,
`data/blockouts/prospekt.json`, `data/sectors/prospekt.json` в scratch.

границы навигации, карта плана рейда, зоны «за картой»), и расширить их до прямоугольника `BOUNDARY_NEW`. Убрать
`REMOVE_OUTSIDE` и прежние заборы по X −152 (Z 112…290), по Z 112 (X −218…−152) и по X −218 там, где листы дают
проходы. Покрытия прирезки. Вокзальная улица `VOKZALNAYA_W` (проезжая часть 7,8 м, тротуары, бордюры, разметка) от
X −248 до южного плеча; в сквере — пешеходное ограждение с обеих сторон с разрывами только на переходах `CROSSINGS_X`,
зебры; вещи сквера, попавшие в полосу улицы, переставить (вагоны и роща южнее остаются). Служебный проезд
`SERVICE_LANE` до Вокзальной. Гаражный кооператив `GARAGES`. Стройка: новый контур `SITE_NEW` без северной полосы

**1б. Объездная** (листы 13, 15; §25.7).

**2. «Ярус»** (лист 11).

**3. Вокзал и площадь** (лист 12).

из PowerShell — `& tools\godot.cmd …`. Кадры этапа глазами игрока — `tools/prospekt_raid_shots.tscn` с
`RAID_LIGHT_VIEW` в `docs/screens/prospekt/s2_<этап>/` (6–10 кадров на этап, y глаз 1,62).

## Сдача этапа

Коммит только своих файлов (`git commit -o -m … -- <пути>`, новые — сначала `git add -N`; перед коммитом
`git branch --show-current` = `main` и `git diff --cached --quiet`), сообщение по-русски `«Проспект»: вторая очередь,
этап …`, в конце — строка `Co-Authored-By` своей модели; `git push origin main`. Запись в `docs/STATUS.md` (свой кусок
в конец). В отчёте постановщику: что сделано, что пропущено и почему, отступления от листов, вывод проверок как есть,
пути к кадрам. Провал проверки не прятать.
