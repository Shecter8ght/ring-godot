# Руки и оружие в одном файле Blender и первая анимация — пошагово

Для Blender 5.2. Пример — ИЗЛОМ-45 и тактическая перезарядка на 72 кадра (2,4 секунды). Каждое действие — с
объяснением, зачем оно, и где искать кнопку.

---

## 0. Обозначения

- **ЛКМ / ПКМ / СКМ** — левая, правая, средняя кнопка мыши (СКМ — нажатие колёсика).
- **Ctrl+P** — зажать Ctrl и нажать P. Клавиши нажимаются, когда курсор мыши стоит **над тем окном**, к которому
  относятся (над 3D-видом — команды 3D-вида, над таймлайном — команды таймлайна). Это главное правило Blender: одна
  и та же клавиша в разных окнах делает разное.
- **Numpad 1, 3, 7, 0** — клавиши цифрового блока справа на клавиатуре (не цифры над буквами). Если цифрового блока
  нет — то же самое есть в меню **View** в шапке 3D-вида (подробности — в разделе 2).
- Если не помните, где команда: **F3** над 3D-видом открывает поиск команд — начните печатать её английское название.

## 1. Словарь

| Термин | Что это простыми словами |
|---|---|
| **Объект** | Любая вещь в сцене: сетка (деталь оружия, руки), риг, камера, пустышка. |
| **Сетка (Mesh)** | Видимая форма — то, что рисуется: корпус, магазин, кожа рук. |
| **Риг (Armature, «арматура»)** | Скелет из костей. Сам не рисуется в игре, но двигает сетку, привязанную к нему. У нас — `FPS_ArmsRig`. |
| **Кость (Bone)** | Звено скелета: плечо, предплечье, кисть, фаланга пальца. Повернул кость — повернулась часть сетки. |
| **Режим объекта (Object Mode)** | Работа с объектами целиком: двигать оружие, привязывать одно к другому. |
| **Режим позы (Pose Mode)** | Работа с костями рига: ставить позу и ключи анимации. Анимация рук делается здесь. |
| **Режим правки (Edit Mode)** | Правка самой формы (сетки или скелета). Для анимации **не нужен** — если попали туда случайно, выйдите (раздел 7). |
| **IK (обратная кинематика)** | Двигаете кисть — плечо и локоть подстраиваются сами, как у живой руки. Кисть ведут кости-цели `ik_hand.R` / `ik_hand.L`. |
| **Полюс (Pole)** | Кость `pole.R` / `pole.L`: точка, куда «смотрит» локоть. Двигаете полюс — локоть уходит в ту сторону, кисть стоит на месте. |
| **Пустышка (Empty)** | Невидимый в игре объект — просто точка с осями. Нужна как «ручка», за которую двигают группу деталей. |
| **Родитель и потомок (Parent)** | Привязка: потомок ходит за родителем. Магазин — потомок пустышки «Магазин»: двигаем пустышку — едет магазин. |
| **Ключ (Keyframe)** | Запомненное положение кости или объекта на определённом кадре. Между ключами Blender сам рисует плавный переход. |
| **Кадр (Frame)** | Один «снимок» анимации. У нас 30 кадров в секунду: кадр 30 — это 1 секунда. |
| **Действие (Action)** | Набор ключей под одним именем — одна анимация («Хват», «Перезарядка»). У одного рига может быть много действий, показывается одно. |
| **Fake User (щит)** | Пометка «не удалять это действие при сохранении, даже если оно сейчас не показано». Без неё неиспользуемые действия пропадают из файла. |
| **Ограничение (Constraint)** | Правило «следуй за…» без настоящей привязки, которое можно плавно включать и выключать. Нужно, чтобы магазин на время ехал в руке. |
| **Child Of** | Ограничение «будь как будто потомком вот этой кости». Ползунок Influence: 0 — правило выключено, 1 — включено. |
| **Set Inverse** | Кнопка в Child Of: «запомни, как предмет сейчас лежит относительно кости, и не дёргайся при включении». |
| **Интерполяция** | Как Blender рисует переход между ключами: **Constant** — без перехода, поза меняется скачком (удобно смотреть одни ключевые позы); **Bezier** — плавно. |
| **Таймлайн (Timeline)** | Полоса внизу с номерами кадров: где мы сейчас и кнопки проигрывания. |
| **Dope Sheet / Action Editor** | Окно, где ключи видны ромбиками по кадрам: их можно выделять, двигать, копировать. Action Editor — его вид для одного действия. |
| **Локальные и глобальные оси** | Глобальные — оси всей сцены. Локальные — оси самой кости или объекта (повернулся объект — повернулись и его оси). Пальцы гнут по локальной оси. |
| **3D-курсор** | Красно-белый кружок в 3D-виде: место, где появляются новые объекты. |
| **Outliner** | Список всех объектов сцены деревом (окно справа сверху). |

## 2. Где что на экране

Откройте Blender — экран делится на окна. Ориентиры для стандартной раскладки **Layout** (вкладка вверху):

- **Самый верх — строка меню:** `File`, `Edit`, `Render`, `Window`, `Help`. Правее — вкладки рабочих пространств
  (`Layout`, `Modeling`, … `Animation`, …). Работаем во вкладке **Layout**; для анимации удобна **Animation** (внизу у неё
  сразу Dope Sheet).
- **Середина — 3D-вид** (сцена). У него своя **шапка** (полоса сверху):
  - слева — выпадающий список режима (`Object Mode` / `Pose Mode` / `Edit Mode`);
  - дальше меню `View`, `Select`, `Add`, `Object` (в режиме позы — `Pose`);
  - справа — **четыре шарика** способа отображения (сетка, серый, материал, рендер) и **левее них кнопка из двух
    наложенных квадратиков — X-ray** (просвечивание, то же Alt+Z).
- **Правый верхний угол 3D-вида — круг с осями X, Y, Z** (навигация): тянуть его ЛКМ — вращать вид; клик по букве —
  смотреть вдоль оси. Под ним иконки: **рука** (сдвиг вида), **лупа** (приближение), **камера** (вид из камеры),
  **сетка** (перспектива / без перспективы).
- **Боковая панель 3D-вида — клавиша N** (над 3D-видом): выезжает справа. На её правом краю вертикальные вкладки
  `Item`, `Tool`, `View`. **Item** — точные числа положения и поворота выделенного; **View → 3D Cursor** — числа 3D-курсора.
- **Справа сверху — Outliner** (список объектов). Стрелочка слева от имени раскрывает содержимое; **глаз** справа —
  спрятать/показать.
- **Справа снизу — Properties** (свойства). **Левый край этого окна — столбик иконок-вкладок.** Наведите мышь на иконку
  и подержите — всплывёт её название. Нам нужны:
  - **Output Properties** (иконка принтера) — частота кадров;
  - **Object Properties** (оранжевый квадратик) — свойства выделенного объекта;
  - **Object Constraint Properties** (сразу под гаечным ключом; всплывает «Object Constraint Properties») — ограничения объекта;
  - **Object Data Properties** у рига (зелёный бегущий человечек) — коллекции костей.
- **Самый низ — Timeline:** посередине кнопки проигрывания (▶), **слева от них — круглая кнопка записи (Auto Keying)**,
  справа поля **Start** и **End** (первый и последний кадр) и номер текущего кадра.
- **Вид с разных сторон** (курсор над 3D-видом): **Numpad 1** — спереди, **Numpad 3** — справа, **Ctrl+Numpad 3** —
  слева, **Numpad 7** — сверху, **Numpad 0** — глазами камеры. Без цифрового блока: меню **View → Viewpoint** (стороны)
  и **View → Cameras → Active Camera** (камера).
- **Вращать вид** — зажать СКМ и вести мышь; **приблизить** — колесо; **сдвинуть** — Shift+СКМ. **Показать выделенное
  крупно** — Numpad «.» (точка на цифровом блоке) или **View → Frame Selected**.

## 4. Новый файл

1. **File → New → General.** *Зачем:* пустая сцена со стандартной раскладкой.
2. Удалите куб, лампу и камеру по умолчанию: в 3D-виде **A** (выделить всё) → **X** → **Delete**. *Зачем:* они
   мешают, свою камеру принесём с руками.
3. **Properties → Output Properties** (иконка принтера) → панель **Format** → **Frame Rate: 30**. *Зачем:* игра
   проигрывает клипы на 30 кадрах в секунду; при другой частоте анимация в игре пойдёт быстрее или медленнее.
4. **File → Save As** → папка `Анимации` → имя `ИЗЛОМ45_Владелец_v01.blend` → **Save As**. *Зачем:* дальше сохраняйте
   **Ctrl+S** почаще — Blender иногда падает.

## 5. Оружие в своих осях

У ИЗЛОМа все детали лежат так, что их общее начало — точка (0, 0, 0) сцены, а оси такие: **X — к дулу, Y — влево,
Z — вверх**. Мы сначала соберём оружие здесь, в нуле, и только потом перенесём в руки — так проще задать точные
числа.

1. **File → Append** → найдите `SMG03_Game_LP.blend` → ЛКМ дважды по нему (Blender показывает файл как папку) →
   откройте папку **Object** → выделите все детали (ЛКМ по первой, Shift+ЛКМ по последней), **кроме `Mag30`** →
   кнопка **Append** справа внизу.
   *Зачем:* Append копирует детали в ваш файл (в отличие от Link, который только ссылается — такие нельзя править).
   `Mag30` — магазин на 30, для первой анимации не нужен.
2. Поставьте 3D-курсор на середину пистолетной рукоятки: **N** → вкладка **View** → панель **3D Cursor** →
   **Location**: X `-0.2122`, Y `0`, Z `-0.035` (ЛКМ по полю, ввести число, Enter).
   *Зачем:* новая пустышка появится в 3D-курсоре, а нам нужна «ручка» оружия именно в рукоятке — тогда поворот оружия
   идёт вокруг кисти, как у живого стрелка.
3. **Add → Empty → Plain Axes** (меню Add в шапке 3D-вида или Shift+A). Переименуйте: **F2** → `ИЗЛОМ` → Enter.
   *Зачем:* это ручка, за которую будем двигать всё оружие.
4. 3D-курсор на гнездо магазина: **Location** X `-0.0355`, Y `0`, Z `-0.0116`. Ещё одна пустышка (**Add → Empty →
   Plain Axes**), имя `Магазин`. Затем **N → Item → Rotation Y: `21.2`**.
   *Зачем:* магазин в ИЗЛОМе стоит с наклоном 21,2°. Повернув пустышку на тот же угол, мы получаем ось (её локальную Z),
   по которой магазин входит и выходит из шахты.
5. Привязки (в режиме объекта; **порядок выделения важен — родителя выделяют последним**):
   - ЛКМ по `Mag13`, Shift+ЛКМ по пустышке `Магазин` → **Ctrl+P → Object (Keep Transform)**;
   - ЛКМ по пустышке `Магазин`, затем Shift+ЛКМ по всем остальным деталям оружия, **последней — по пустышке `ИЗЛОМ`** →
     **Ctrl+P → Object (Keep Transform)**.
   Удобно выделять в Outliner: ЛКМ, Ctrl+ЛКМ — добавить к выделению.
   *Зачем:* теперь всё оружие ходит за пустышкой `ИЗЛОМ`, а магазин — ещё и за своей пустышкой. «Keep Transform» —
   чтобы при привязке ничего не сдвинулось.
6. **Проверка:** ЛКМ по пустышке `Магазин` → **G Z Z** → ведите мышь. Магазин должен скользить вдоль своей оси вниз из
   шахты. **Esc** или ПКМ — отмена, магазин вернётся.
   *Что значит G Z Z:* G — двигать, первая Z — по оси Z сцены, вторая Z — по **своей** оси Z (локальной). Нам нужна своя.

## 6. Руки

1. **File → Append** → `FPS_Arms_v14.blend` → папка **Collection** → **`FPS • Руки и управление`** → **Append**.
   Придут риг `FPS_ArmsRig`, сетка рук `FPS_Arms` и камера `FPS • Camera`.
   *Зачем:* коллекция берёт всё связанное разом.
2. Ещё раз **File → Append** → `FPS_Arms_v14.blend` → папка **Action** → **`VERAS54_Grip_Manual_v02`** → **Append**.
   *Зачем:* это ваш хват с ВЕРАСа — правая кисть в нём уже стоит «на пистолетной рукоятке». Действия, которые ригу не
   назначены, с коллекцией не приходят — поэтому отдельно.
3. ЛКМ по камере `FPS • Camera` (в Outliner) → **View → Cameras → Set Active Object as Camera** (или Ctrl+Numpad 0).
   *Зачем:* камера стоит там, где глаза игрока, и с тем же углом обзора, что в игре. Всё, что видно в ней (Numpad 0),
   увидит игрок.
4. Устройство рига. Выделите `FPS_ArmsRig` → **Properties → Object Data Properties** (зелёный бегущий человечек) →
   панель **Bone Collections**. У каждой строки глаз:
   - `01 • Управление` — кости, которыми анимируют (оставить видимой);
   - `02 • Пальцы` — фаланги (видимой, когда ставите пальцы);
   - `03 • Кости рук` — внутренние кости, их не трогают (спрятать).
   Главные кости:
   - **`Weapon_CTRL`** — ручка оружия. Обе цели кистей — её потомки, поэтому повернули её — оружие и обе руки
     повернулись вместе (так наклоняют оружие при перезарядке);
   - **`ik_hand.R`, `ik_hand.L`** — кисти: **G** двигает, **R** поворачивает; предплечье и плечо следуют сами (IK);
   - **`pole.R`, `pole.L`** — направление локтей;
   - **`f_index`, `f_middle`, `f_ring`, `f_pinky` `.01`–`.03`** — указательный, средний, безымянный, мизинец
     (01 — от ладони, 03 — кончик); **`thumb.01`–`.03`** — большой.

## 7. Режимы рига — важно

- **В режим позы:** выделите `FPS_ArmsRig` → **Ctrl+Tab** (или список режима в шапке 3D-вида → **Pose Mode**).
- **Обратно:** снова **Ctrl+Tab** (или список → **Object Mode**).
- **Не нажимайте просто Tab на риге** — это **режим правки скелета (Edit Mode)**: кости там меняют сам скелет, а не
  позу. Если попали — Tab ещё раз (вернёт в режим объекта).
- Выделить кость: в режиме позы ЛКМ по ней в 3D-виде. Если кость не видно или не попадаете — Outliner → раскройте
  `FPS_ArmsRig` → `Pose` → ЛКМ по имени кости.

## 8. Вложить оружие в руки

1. Выделите `FPS_ArmsRig`, перейдите в режим позы (Ctrl+Tab).
2. Внизу окно **Dope Sheet** (во вкладке Animation оно есть сразу; в Layout — наведите на таймлайн, в его левом
   верхнем углу выпадающий список типа окна → **Dope Sheet**). В шапке Dope Sheet рядом слева выпадающий список вида →
   **Action Editor**. В середине шапки — поле действия: иконка-список слева от пустого поля → выберите
   **`VERAS54_Grip_Manual_v02`**. Если рядом есть поле **Slot** и поза не изменилась — выберите в нём единственный слот.
   *Зачем:* так ригу назначается действие — кисти встают в ваш хват.
3. Режим объекта (Ctrl+Tab). ЛКМ по пустышке `ИЗЛОМ` → **N → Item**: **Location** `-0.14`, `-0.323`, `1.635`;
   **Rotation** `0`, `0`, `-90`.
   *Зачем:* эти числа ставят рукоятку ИЗЛОМа туда, где была рукоятка ВЕРАСа, — прямо в правую кисть, и разворачивают
   оружие дулом вперёд от камеры (у рук «вперёд» — это минус Y сцены).
4. Подгоните на глаз — **двигайте пустышку `ИЗЛОМ`, а не руки** (G и R): справа (Numpad 3) — рукоятка в ладони,
   указательный у спуска; сверху (Numpad 7); глазами игрока (Numpad 0). **Alt+Z** (X-ray) — видно, где кисть ушла в
   рукоятку. *Зачем:* хват кисти — ваш, проверенный; проще поставить оружие под кисть, чем перегибать кисть.
5. **Привязать оружие к рукам.** В режиме объекта: ЛКМ по пустышке `ИЗЛОМ` → Shift+ЛКМ по `FPS_ArmsRig` (риг стал
   активным, пустышка тоже выделена) → **Ctrl+Tab** (риг в режиме позы, пустышка осталась выделенной) → ЛКМ по кости
   **`Weapon_CTRL`** → **Ctrl+P → Bone**.
   *Зачем:* теперь оружие ходит за `Weapon_CTRL` вместе с кистями. Если оружие куда-то прыгнуло — Ctrl+Z и повторить,
   проверив, что выделены именно пустышка и кость.
6. **Левая рука:** в режиме позы ЛКМ по `ik_hand.L` → G (двигать) и R (поворачивать) — под передний блок. Локоть —
   `pole.L`. Пальцы — по правилам из шага 12.

## 9. Свой хват — отдельным действием

1. В **Action Editor** справа от имени действия — иконка **двух листов** (подсказка «New Action» — делает копию
   текущего действия). Нажмите → появится копия → ЛКМ дважды по имени → `IZLOM45_Хват_владельца_v01` → Enter.
   Нажмите **щит** рядом с именем (Fake User) — он подсветится.
   *Зачем:* хват ВЕРАСа остаётся нетронутым, а ваш хват ИЗЛОМа — своим действием. Щит — чтобы действие не пропало,
   когда вы переключитесь на другое.
2. Кадр **1** (поле текущего кадра на таймлайне или **Shift+←**). Курсор над 3D-видом, режим позы: **A** (выделить
   все кости) → **I** (поставить ключ).
   *Зачем:* хват записан на кадр 1. От него начинаются и им кончаются все клипы.

## 10. Действие перезарядки

1. Снова иконка двух листов → имя `IZLOM45_Перезарядка_v01` → щит.
   *Зачем:* перезарядка — копия хвата, кадр 1 уже правильный.
2. Таймлайн справа: **Start `1`**, **End `72`**. *Зачем:* 72 кадра = 2,4 секунды, обычная тактическая перезарядка.
3. Конец как начало: в Action Editor выделите ромбики кадра 1 (ЛКМ по ромбику на верхней строке «Summary» выделяет
   все ключи этого кадра) → **Ctrl+C** → поставьте кадр 72 (ЛКМ по числу 72 на шкале) → **Ctrl+V** (курсор над Dope
   Sheet). *Зачем:* в игре клип стыкуется с позой покоя — если последний кадр не совпадёт с первым, будет рывок.

## 11. Магазин в левой руке

Магазин сам лежит в оружии, но с кадра, когда рука его взяла, и до кадра, когда вставила, он должен ехать в руке.

1. Режим объекта. ЛКМ по пустышке **`Магазин`** → **Properties → Object Constraint Properties** → **Add Object
   Constraint → Child Of** (в колонке Relationship).
2. В появившейся панели: **Target** → `FPS_ArmsRig`; ниже появится поле **Bone** → `hand.L`.
   *Зачем:* «будь потомком кисти» — пока ограничение включено, магазин движется с левой кистью.
3. Включение и выключение по кадрам (у ползунка **Influence**: навели курсор → **I** ставит ключ; поле станет жёлтым):
   - **кадр 13** (рука ещё не взяла): Influence `0` → I;
   - **кадр 14** (рука обхватила магазин): Influence `1` → нажмите **Set Inverse** → I на Influence;
   - **кадр 55** (магазин вставлен до конца): Influence `1` → I;
   - **кадр 56**: Influence `0` → I.
   *Зачем:* на 14-м магазин «прилипает» к кисти без скачка (Set Inverse запоминает, как он лежит относительно руки), на
   56-м — «отлипает» и остаётся в шахте.
4. Если на 56-м магазин дёрнулся: на кадре 55 подвиньте `ik_hand.L`, чтобы магазин сел ровно в шахту, и проверьте
   снова.

## 12. Позы по кадрам

Сначала ставьте только **ключевые позы**, без плавности: в Action Editor **A** (все ключи) → **T → Constant**. Так
видны чистые позы, и легко понять, какая не удалась.

Как ставить позу на кадре: переходите на кадр (ЛКМ по числу на таймлайне) → в режиме позы выделяете нужные кости →
двигаете/поворачиваете → **I**. Двигать без I бесполезно: при смене кадра поза вернётся к ключам.

| Кадр | Что делать | Какие кости |
|---|---|---|
| 1 | хват (уже есть) | — |
| 6 | оружие наклонить на 15–20° шахтой к левой руке и чуть вверх; левая сходит с блока | `Weapon_CTRL` (R), `ik_hand.L` |
| 12 | левая кисть у донца магазина, пальцы раскрыты | `ik_hand.L`, пальцы левой |
| 14 | пальцы обхватили магазин (и Child Of включается — шаг 11) | пальцы левой |
| 22 | рука с магазином вниз по оси магазина, примерно на 15 см | `ik_hand.L` |
| 32 | рука ушла вниз из кадра («в подсумок») | `ik_hand.L` |
| 40 | рука вернулась с «новым» магазином под шахту | `ik_hand.L` |
| 50 | магазин вошёл до конца | `ik_hand.L` |
| 54 | досылка: ладонь подбивает донце, оружие чуть вздрагивает | `ik_hand.L`, `Weapon_CTRL` |
| 60–62 | левая обратно на передний блок | `ik_hand.L`, пальцы левой |
| 70 | оружие в исходное положение | `Weapon_CTRL` |
| 72 | хват (уже есть) | — |

**Правила пальцев** — из-за их нарушения пальцы и выглядели «изломанными»:
- Фалангу гнуть **только вокруг её собственной оси**: выделить фалангу → **R X X** (вторая X — своя ось кости). У
  **большого пальца** другая ось: **R Z Z**.
- **Никогда не крутить фалангу вдоль неё самой** (R Y Y) — это и есть «излом».
- Средняя фаланга (`.02`) сгибается **не меньше** концевой (`.03`). Согнутый кончик при прямой средней выглядит
  сломанным.
- Разводить пальцы веером (у пальцев это R Z Z) — только у основания (`.01`) и немного.
- Глазами игрока (Numpad 0) и с двух сторон — после каждой позы. **Alt+Z** — видно, где палец ушёл в оружие.

Когда все позы устраивают: **A → T → Bezier** — Blender нарисует плавные переходы. Дальше смотрите (**пробел** —
проигрывание, ещё раз пробел — стоп; **←/→** — по одному кадру) и правьте переходы, добавляя ключи между позами.

**Удобно:** один раз сделайте 3–4 позы кисти («обхват магазина», «раскрытая», «на блоке») и сохраните их в
библиотеку поз: выделите кости пальцев → **F3** → наберите `Create Pose Asset` → имя. Потом они лежат на полке
ассетов внизу 3D-вида в режиме позы — ставятся одним кликом, а перетаскиванием с зажатой ЛКМ смешиваются с текущей.

## 13. Сохранить и отдать в игру

**Ctrl+S.** Напишите имя файла и что это за клип (тактическая или с пустым магазином). В игру переводит агент:
переносит движение пустышки «Магазин» на кость рига ИЗЛОМа и выгружает. Он же может прогнать замер — где пальцы
входят в оружие (`tools/anim_from_video/fix_clip.py`), — и назвать кадры, которые стоит поправить.

## 14. Если что-то не так

| Что случилось | Почему и что делать |
|---|---|
| Сменил кадр — поза сбросилась | Не поставили ключ. Вернитесь на кадр, поставьте позу, **I**. |
| Нажал Tab на риге — кости ведут себя странно | Это режим правки скелета. **Tab** ещё раз, затем **Ctrl+Tab** — режим позы. |
| I ничего не делает | Курсор не над 3D-видом или ничего не выделено. |
| Рука не дотягивается, плечо «вытянулось» | Цель кисти слишком далеко: верните `ik_hand` ближе или подвиньте оружие (`Weapon_CTRL`) к руке. |
| Локоть вывернут | Подвиньте `pole.R` / `pole.L` в ту сторону, куда должен смотреть локоть. |
| Магазин прыгнул при включении Child Of | Set Inverse нажимали не на том кадре. На кадре включения: Influence 1 → **Set Inverse** → I. |
| Действие пропало после сохранения | Не нажат щит Fake User у действия. |
| Испортил — Ctrl+Z | Отмена последнего шага, можно нажимать много раз. |
