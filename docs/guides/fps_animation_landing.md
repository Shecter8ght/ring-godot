# Сайт: первая FPS-анимация

- Сайт: https://ring-fps-animation-guide.ovchinnikov-dsgn.chatgpt.site
- Доступ: только владельцу, вход через ChatGPT.
- Исходный документ: `fps_animation_first_steps.md` в этой папке.
- Локальная готовая страница: `docs/sites/fps-animation/dist/index.html`.
- Исходники сайта и инструкция пересборки: `docs/sites/fps-animation/README.md`.
- Сайт имеет собственный Git-репозиторий Sites внутри `docs/sites/fps-animation/`.
  Не добавлять эту папку в корневой Git как submodule/gitlink. Исходники сохранены и отправлены
  в репозиторий Sites; опубликована версия 1, commit `38496f69922e3dda8a9e61b8466006504ce9e98d`.

Полный текст 15 разделов, быстрый путь через готовый риг, схема управления, поиск,
сохранение прогресса, интерактивная шкала 12 ключевых поз, копирование путей, скачивание
Markdown, печатная версия. Модели и анимации Blender не менялись.

Проверено в браузере: переходы с автоматическим раскрытием шага, поиск и отсутствие результатов,
отметки и сброс прогресса, выбор поз, раскрытие всех разделов. На ширине 320 и 390 пикселей
проверена адаптивность; после исправления минимальной ширины сетки на 320 пикселях нет
горизонтального переполнения даже при раскрытых 15 разделах. Ошибок JavaScript в консоли нет.
Опубликованный адрес проверен до штатного экрана входа владельца; доступ сайта не расширялся.

Сборка: `python docs/sites/fps-animation/build.py` из корня проекта.
