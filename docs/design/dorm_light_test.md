# Общежитие — пробный свет, редакция 5

2026-10-28. Геометрия этапа 1, редакция 4 (`0da558c8`), принята владельцем. Здесь проверяется
свет на том же сером плане перед модулями Blender и окончательной настройкой этапа 5.
Масштаб, планировка, мебель 1:1, базовые цвета и 14 камер сохранены.

## Запуск

```bat
tools/dorm_study.cmd
tools/godot.cmd --headless --fixed-fps 60 res://tools/dorm_study.tscn -- verify
tools/godot.cmd --windowed --resolution 1600x900 --disable-vsync res://tools/dorm_study.tscn -- shots
tools/godot.cmd --windowed --resolution 1600x900 res://tools/dorm_study.tscn -- bake
```

F1–F4 либо кнопки сверху: **вечер А (SDFGI)**, **вечер Б (VoxelGI)**, **ночь А**, **пасмурно А**.
При запуске — вечер А. Esc освобождает мышь для FOV и переключателей SSIL, пыли и обработки.
По умолчанию FOV 80° по горизонтали, ползунок 60–110°; SSIL выключен, пыль и обработка включены.
Прежние WASD, E, M, F, 1–9 / 0 и N / B работают как раньше.

«Обработка кадра» одновременно отключает Filmic, экспозицию, LUT, приглушение цветов, glow, зерно,
резкость и виньетку. SSAO, GI, отражения и отдельные переключатели SSIL / пыли сохраняют своё состояние.
Привыкания глаза нет: фиксированная экспозиция позволяет сравнивать кадры без дрейфа.

## Собственные настройки

Настройки других карт не импортируются. Источник — `tools/dorm_lighting_data.py` → `dorm.json`:
группы `lights`, `probes`, раздел `environment`; в сцене — узел `Lighting`.

| Параметр | Значение |
|---|---|
| Вечер | солнце на высоте 12°, поворот 145°, тёплое `ffd4a0`, энергия 3,2; холодное небо |
| Ночь | солнце, небо и оконные источники выключены, только лампы |
| Пасмурно | рассеянный свет окон без направленного солнца |
| Оконное небо | источники в плоскости окон, дальность 8 м, угол 78°, мягкие тени; энергия 0,32 / 0 / 1,15 |
| Коридор | каждый второй пролёт, треть ламп погашена, 2850 K, дальность 4,5–4,6 м |
| Санитарные помещения | 4500 K; ключевой свет умывальной с тенями |
| Комнаты | по очереди окно / условная настольная лампа на высоте 0,95 м / без своей лампы |
| Вахта / гостиная / лестница | свои локальные источники, ключевые с тенями |
| SDFGI | 4 каскада, ячейка 0,12 м, occlusion, energy 2,4, bounce feedback 0,65 |
| VoxelGI | объём на каждый из трёх открытых этажей, subdiv 256 |
| Отражения | проба на помещение и отрезок коридора, box projection, UPDATE_ONCE, до 32 ближайших на высоте камеры |
| Тени | локальный атлас 4096; источники оконного неба и ключевые лампы затеняются стенами |
| Обработка | Filmic, экспозиция вечер 1,15 / ночь 1,55 / пасмурно 1,25; RGB LUT 256 отсчётов, saturation 0,91 |
| Эффекты | SSAO; SSIL отдельно; зерно 0,005, виньетка 0,08, `screen_sharpen.gdshader` 0,65 |
| Пыль | volumetric fog density 0,006, длина 38 м, без общего ambient inject |

Оконные источники приближают рассеянный свет неба; стены отсекают его, глубина комнаты остаётся темнее.
Они активны на высоте камеры, ночью выключены. Полосы тёплого солнца формируют настоящие рамы и откосы.
Условные настольные источники пока без моделей светильников: предметы остаются для этапа наполнения.

Данные проб сохранены для всех открытых помещений; ограничен только одновременно активный набор,
чтобы не переполнить атлас. При смене времени обновляются и комнаты, куда игрок зайдёт позже.
Зеркала используют локальные пробы и SSR. Переключение света не меняет материалы.

## Воксельное запекание в варианте Б

`data/blockouts/dorm_voxel/floor_1.res` … `floor_3.res` содержат воксельную геометрию и её материалы.
**Свет ламп и солнца не запекается в эти файлы:** все источники BAKE_DYNAMIC, LightmapGI нет.
Вечер А работает без ресурсов VoxelGI. При выборе Б читается кэш; при отсутствии или несовпадении
SHA256 геометрии стенд пересоздаёт его. `-- bake` принудительно пересоздаёт три объёма.

Первый замер — 3,114 с; актуальный после исправления порогов — 2,938 с. Точные времена по этажам,
размеры ресурсов и SHA256 — `bake.json`. Три сжатых файла занимают около 4,4 МБ.
Изменения энергии и времени не требуют запекания; после изменения стен, окон или замены серых объёмов
модулями Blender кэш обязательно пересоздать.

Без VoxelGIData прямой свет, его тени и отражения остаются, пропадают отскоки и пространственное затенение
VoxelGI. Рассеянный фон тогда может выглядеть ровнее, а не просто темнее. Сравнительный кадр
`light_evening_B_unbaked_01_corridor.png` снят с реально отключёнными данными трёх объёмов.

Подвижные двери получают GI и отбрасывают прямые тени, но не входят в неподвижную сетку и не служат
динамическими препятствиями для GI. Это одинаковое ограничение текущего сравнения А/Б.
Вокселизация всех 69 полотен каждый кадр давала около 24 FPS; после исключения из расчёта геометрии GI
эта стоимость ушла. Открывание, видимые полотна и физические коллизии сохранены.

Основание для разделения геометрии и динамического света — документация Godot:
[VoxelGI](https://docs.godotengine.org/en/stable/classes/class_voxelgi.html),
[Light3D](https://docs.godotengine.org/en/stable/classes/class_light3d.html),
[SDFGI](https://docs.godotengine.org/en/stable/tutorials/3d/global_illumination/using_sdfgi.html).

## Две поправки геометрии

- За поворотом хозкрыла по два портала на этаж: балка 0,40 × 0,40 м, пилястры шириной 0,45 м,
  выступ 0,18 м. По существующим межкомнатным стенам через два служебных модуля (8,6 м), отдельные
  группы beams / pilasters / baseboards. Холл сохранён.
- Треугольники у 203/204 — верхние грани стен нижнего этажа, совпавшие с полом верхнего.
  Только скрытые торцы утоплены на 5 мм в плиту. Наличники, плинтусы и чистые размеры сохранены.
  Проверка при ровном свете — `light_geometry_check_fov95_01_corridor.png`.

## Кадры и замеры

`light_views.json`: для четырёх вариантов по 14 прежних камер при 80° и коридор / комната / лестница
при 95°. Ещё по два кадра вечера А с SSIL, без пыли и без обработки; для Б — кадр без VoxelGIData.
Всего **75 кадров**, плюс нейтральная проверка порогов. Позиции и состояния эффектов записаны в manifest.
Исходные 17 PNG редакции 4 побайтно сохранены как `stage1r4_*`; прежние `stage1_*` тоже остаются.

`validation.json`: все 68 открытых помещений, лестница вверх/вниз, двери, турникет и оба выхода
в обе стороны, новые порталы. Blender, текстуры, провода и мусор на этом шаге не разрабатывались.

`light_performance.json`: V-Sync выключен, FPS не ограничен, одинаковые 80° и точки 01_corridor / 09_lounge.
После прогрева, не менее 120 кадров и 2 секунд на точку. PNG и viewport — 1920 × 1080 (базовый размер
проекта, окно запуска 1600 × 900). Это пустой серый стенд без NPC и будущего наполнения, а не прогноз рейда.

`gpu_frame_ms` — интервал GPU от маркера frame_pre_draw до конца viewport, включая предшествующий расчёт GI;
время только viewport и p95 также сохранены. Число теневых источников — пересечение области влияния с
фрустумом камеры, верхняя граница без учёта закрывающих стен. Лампы и оконное небо посчитаны отдельно.

При выходе рендера остаётся прежнее предупреждение о 7 Texture RID. Итоговые прогоны должны завершаться
без ошибок скриптов и провалов геометрии. Вариант света выбирает владелец.
