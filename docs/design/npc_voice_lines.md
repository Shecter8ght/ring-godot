# Реплики бойцов для озвучки

В кавычках игровой текст. С 2026-11-13 назначены 612 записей ElevenLabs: боевые реплики, рация, пролог, задания и реплики игрока. В Sonora их можно найти в категории «Голоса ИИ и персонажей» по тексту или имени персонажа и заменить через обычный импорт. Соответствие текста и назначения — `data/npc_voice_map.json`; 44 реплики Сергея и Антона отложены до отдельных голосов.

| Когда звучит | Реплика | Событие Sonora |
|---|---|---|
| Потерял игрока, начинает искать | «Ушёл… Ищем.» | `ai_search` |
| Осматривает место, откуда был шум | «Проверю тут…» | `ai_investigate` |
| Игрок зашёл за стоп-линию кордона | «Стой! Назад за линию!» | `ai_cordon_warning` |

## Остальные реплики

| Ситуация | Реплики в игре |
|---|---|
| Заметил игрока или по группе открыли огонь | «Контакт!» · «По нам стреляют!» |
| Узнал чужую группу | «Мародёры!» · «Периметр! Наёмники!» · «Тут крысы засели!» · «Чужая группа! Контакт!» |
| Уходит сбоку, перебегает, прикрывает или отходит | «Обхожу!» · «Двигаюсь!» · «Прикрываю!» · «Отхожу!» |
| Бросает гранату | «Граната!» |
| Заряжает, остался без патронов или меняет оружие | «Перезаряжаюсь!» · «Пустой!» · «Перехожу на запасное!» · «Основное!» |
| Упал раненым или поднялся | «Меня зацепило!» · «Живой!» |
| Идёт помочь, тащит раненого или не может добраться | «Держись, иду!» · «Тащу! Прикрой!» · «Не пройти к тебе!» |
| Нашёл что-то ценное | «Есть кое-что» |
| Снайпер меняет позицию при тумане | «Ничего не видно — ближе работаем» · «Туман ушёл. На позицию.» |
| Жилец прогоняет игрока | «Пошли вон отсюда!» |
| Ведущий чужого отряда | «Отходим!» · «Проверю тела. Прикройте.» · «Заперто. Ищем ключ.» · «Ключ у меня» |
