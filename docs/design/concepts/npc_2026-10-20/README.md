## Как использовать

- Файл с `_front_` — основной референс спереди: одна фигура целиком,
  руки в T-позе, без текста и дополнительных изображений.
- Файл с `_sheet_` — сверху фигура спереди, сзади и в правый профиль;
  снизу голова спереди, в правый профиль и в три четверти.
- Для моделирования сначала зафиксировать пропорции по основному фронту,
  затем сопоставлять с задним и боковым видами, голову уточнять по крупным планам.
- Целевой рост исходной серии — около 178 см; точный масштаб задаётся в Blender.
  Пиксельные размеры изображения сами по себе не задают рост модели.
- У всех одинаковые серые шорты, светлый серый фон и нейтральный студийный свет.
  Одежда и снаряжение будут строиться отдельными объектами на выбранных телах.

Это визуальные референсы первого прохода. Между самостоятельно сгенерированным
фронтом и листом возможны небольшие различия; при построении объёма их нужно
свести к одной анатомии. Изображения не являются точными измерительными чертежами.
Окончательный выбор внешностей остаётся за владельцем.

## Исходные запросы

В `prompts/` сохранён полный запрос для каждого из 12 изображений.
Лист М02 создан первым. Для остальных листов М02 использовался как ориентир
компоновки и света с новым описанием внешности. Для отдельных фронтальных
T-поз использовался соответствующий лист персонажа, чтобы сохранить личность.

[manifest.json](manifest.json) содержит перечень файлов и фактические размеры.
`.gdignore` сохраняет набор как рабочие референсы вне импорта игровых ресурсов.
