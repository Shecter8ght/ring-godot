# Настройка положения оружия

Открыть: главное меню → **Настройка положения оружия**, либо `WEAPON_POSE.cmd` в корне проекта.
В редакторе: `scenes/debug/weapon_pose_lab.tscn`, F6 (запустить текущую сцену).

1. Выбрать оружие, его позу (от бедра, прицеливание, опущенное) и стойку игрока.
2. Двигать ползунки или вводить точные значения. Смещения — **добавка к исходной позе**, в сантиметрах:
   X: плюс вправо; Y: плюс вверх; Z: плюс ближе к глазам, минус дальше. Повороты — в градусах.
3. **F7** или «Исходная поза для сравнения» временно убирает все поправки, сохраняя черновик.
4. **F6** или «Проверить в движении» скрывает панель: WASD, мышь, ПКМ, стрельба, R, бег и смена стойки
   работают как в игре. Ещё раз F6 — вернуться к настройке выбранной позы. Esc при открытой панели скрывает её;
   при закрытой открывает обычное меню паузы.
5. **Сохранить все настройки / Ctrl+S** сохраняет все оружия и позы. Если включено «Использовать сохранённые позы
   в игре», они сразу действуют в обычной игре, включая последующие запуски. Выключить галочку и сохранить —
   вернуть обычные игровые позы, сохранив свои настройки для стенда.

«Сбросить эту позу» возвращает 0 см / 0° только у выбранного оружия и позы; сброс тоже нужно сохранить.
«Загрузить сохранённое» отменяет все несохранённые изменения стенда. Копирование даёт JSON выбранной позы
с id оружия, сантиметрами и градусами для передачи значений.

Настройки локальные, общие для сохранений игры: `user://weapon_poses.cfg` (обычно
`%APPDATA%/Godot/app_userdata/RING/weapon_poses.cfg`). Игровой профиль и снаряжение на стенде не расходуются.
Поправки общие для всех сборок одной модели оружия; механика, коллиматор и оптика сохраняют свои базовые линии
прицеливания. Изменение X/Y и поворота в ADS позволяет намеренно сместить линию прицела с центра экрана.

Переходы между тремя позами плавные. Сохранённая поправка применяется в CameraRig к готовой позе, до отведения
оружия от стен и до расчёта хвата рук. Вплотную к преграде итоговая поза может отличаться от ползунков.
Лёжа опущенная стойка отсутствует по игровым правилам; стенд переключает её на «от бедра».

Проверка: `tools/godot.cmd --headless res://tools/weapon_pose_test.tscn`.
С окном: `tools/godot.cmd --windowed --resolution 1600x900 res://tools/weapon_pose_test.tscn -- out=<папка>`
сохраняет снимки интерфейса и поз. Проверка использует отдельный файл настроек.
